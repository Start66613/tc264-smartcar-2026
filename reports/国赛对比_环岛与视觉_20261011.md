# 国赛模块对比报告 —— 环岛 & 视觉（2026-10-11 深查版）

> 立场：我们（TC264_VisionTrack v141/v142，现役） vs 参考库中的国赛/准国赛队实现。
> 所有外来成绩为作者/合集自述，未独立核验；**看的是方法与结构，不是名头**。
> 本报告只对比"环岛、视觉"两个用户重点模块；每条差异都给出"要不要学"的判断。

## 一、总览：各方实现路线一览

| 队伍/项目 | 环岛路线（一句话） | 视觉路线（一句话） | 对我们的价值 |

## 二、环岛模块深对比（重点）

### 2.1 五条路线对照

| 维度 | 我们 v141 | CQU | 22届决赛 | HammerTa | SJTU |
|---|---|---|---|---|---|
| **进环检测** | 点3/点2 模板匹配 + 165ms 窗口确认2次 | 多特征同时满足（leftdown+lcenter+短段+里程） | 逐行"中点撞黑点" + 宽度>30 + 条件组 | 角点位置 + 横断率(float) + 边线长度比 | 双 L 角点 |
| **环内怎么找路** | **依赖原始视觉**（左转协调：大左转→右转118） | **connect_line 按阶段强制画线**（如从(55,30)拉到(5,115)） | **单侧补线**：贴边线 + 宽度上限(+11) 补出另一侧 | **单边线 + 学习路宽半值**：`col - TrackWild[row]/2` | 远线切换（固定列找远端） |
| **进度判定** | 视觉锚点（点2二次检出） | **陀螺角度**（10°/45°/64°）| **时间倒计时**（Annulus_Delay[] 预设） | 视觉状态推进 | 视觉状态推进 |
| **退出判定** | 点1模板 + 超时 | 64° 且见 rightdown | 倒计时到期 | 出环补线 + 状态 | END 阶段 |
| **方向（左/右环）** | 视觉（右环专用，四环需扩展） | 特征自动识别 | **预设序列**（第几圈哪个环） | 自动识别 | 自动识别 |
| **失败保护** | 8s 保险强制关闭 | （未见） | 倒计时到期自然退出 | （未见） | （未见） |

### 2.2 关键差异与我们该不该学

**差异1：环内"看"vs"画"（最重要）**
- 国赛四支队伍中三支（CQU/22届/HammerTa）在环内**都不完全依赖原始视觉**：CQU 按阶段直接画目标线；22届把被环壁干扰的边线用"宽度上限"规则补回去；HammerTa 用"单边线+宽半值"算中线。
- 我们 v141 环内仍以原始视觉为主（只用"大左转→右转"做纠正）。
- **第3/4轮失败（长失线飞出）正是"看"路线的固有风险**：视觉一旦连续全白，我们没有任何"画"的兜底。
- **建议采纳**（用户已批准方向）：环内长失线（≥2拍）→ 注入温和右转合成线（mid≈118）+ 降速。这是"画"的最小版本，与 CQU 思路一致。
- 备注：22届决赛的"环内补线"更狠——环内直接把整个内侧补成"看不见"，只用外侧环壁+宽度上限算中线。**若我们将来的环内持续误锁，可升级为这个。**

**差异2：进度判定——陀螺/时间 vs 视觉锚点**
- CQU 用陀螺角度卡阶段（视觉暂时看不到环壁也知道转到哪）；22届甚至用**预设毫秒表**（因为赛道固定，倒计时最稳）。
- 我们坚持视觉锚点（不依赖预设）。优点：不依赖赛前标定；缺点：锚点看不见时无参照。
- **建议保持现状**（视觉为主），但把 **8s 保险的计时逻辑视为我们的"时间兜底"**（已实现）。陀螺分段作为备选（将来若环内锚点频繁丢失再上）。

**差异3：方向识别**
- 22届用"预设环序"（Annulus_Count[]），最简单但需要赛前知道环的序列；其余（CQU/HammerTa/SJTU）自动识别。
- 我们目前是"右环专用"。**四环（A–D）全比赛要求均须入环** → 必须扩展为自动识别左右。
- **建议**：把"点3/点2"升级为"右环/左环双模板"（镜像特征），保留确认窗口逻辑。

**差异4：失败保护**
- 只有我们有 8s 保险（自研）——国赛实现里未见同类（他们的保险是"倒计时退出"这种天然保底）。
- **保留并骄傲**：这是我们的稳定器。

### 2.3 结论（环岛）

| 项 | 判断 |
|---|---|
| 我们的优势 | 视觉自适应（不依赖预设环序）、8s 保险、左转协调、完整的"环外零改动"隔离纪律 |
| 我们的短板 | ①环内过于依赖"看"（无画线兜底）②仅支持右环 ③长失线时"冻结+不降速"（track_core 层） |
| 学什么 | CQU 的"阶段画线"最小版（盲区注右转+降速）；四环双模板；其余保持 |
| 不学什么 | 预设环序/毫秒表（我们是测试环境，不应绑死赛道布局；且用户明确"不做正方向对照，主攻反方向"） |

## 三、视觉模块深对比（重点）

### 3.1 栈对照表

| 环节 | 我们 | SJTU | CQU | NEUQ | HammerTa |
|---|---|---|---|---|---|
| **阈值** | 两级整幅大津（亮占比>62% 时二级切蓝白） | **局部自适应阈值**（block 窗口） | 整幅大津（Fast_otsuThreshold） | 大津+偏置 | 大津+腐蚀 |
| **预处理** | 无 | 高斯模糊/腐蚀/膨胀/去畸变 remap | 腐蚀 | 腐蚀 | 黑区/白区 |
| **边线** | 双边界逐行追踪（共用资格闸门防劫持） | 八邻域 | 逐行左右边线 | BFS 连通域 | 八邻域 |
| **采样** | 逐行 188→128 重采样 | **透视校正后等距采样** | 逐行 | 连通域内 | 逐行 |
| **中线** | 模型插值 + 全帧加权中值 + 种子海选（长链竞争） | 角点 + 网格 | 逐行 | 域评分 + 预瞄点 | 单边+宽半值 |
| **误差** | e=(94-mid)/94 + 滤波/微分 | 前瞻点几何 | **前瞻行±7行平均** | 预瞄点 x−中心 | 前瞻 |
| **环/十字** | 锚点特征 + 补线（edge3 闸门修复） | 角点 + 远线切换 | connect_line | - | 角点/横断率 |

### 3.2 关键差异与我们该不该学

**差异1：整幅大津 vs 局部自适应阈值**
- SJTU 用局部窗口阈值（每像素跟邻居比）——**天然抗光照不均**，但计算量 = 全图 × block²。
- 我们的两级大津是"整幅 + 场景特判"（蓝白赛道专门优化）——**快，但强光/暗角变化时整幅统计会失准**（这正是"盲区全白"的部分贡献因素之一：不是没线，而是被整幅阈值化成了白）。
- **判断**：暂不换（TC264 算力+实时性考虑；且我们赛道是稳定室内）。**但如果"盲区为什么全白"的存帧证据显示是阈值问题 → 局部阈值是正解。**（盲区自动存帧已加，等图判断）

**差异2：误差取"近处行"还是"前瞻行"**
- CQU：`err = 前瞻行附近 7 行平均 − 80`（qianzhan 行，靠上=看得远）
- 我们：全帧加权中值（近处权重大）+ 起主导
- **判断**：各有优劣——前瞻更平滑（对近处噪声不敏感），全帧更保守（近处精度高）。我们的滤波器已经在补偿。**暂不换。**

**差异3：等距采样/去畸变**
- SJTU：remap 表把鱼眼/梯形畸变去掉后再等距采样 → "同一行=同一物理距离"，前瞻距离精确。
- 我们：无畸变校正 → **远处的行间距严重压缩**（"跳变30px"里有一部分是几何畸变，不全是识别错误）。
- **判断**：中等价值。做完环岛和盲区修复后，可以做一次"去畸变标定"（有 RUBO/UDIPM 工具链参考）。**P2 排队。**

**差异4：中线算法**
- NEUQ（TC377）"BFS 连通域 + 域评分 + 预瞄点"= 我们 v121 种子海选的思想同源，但他们多了"宽度上限 1.2×高排除过宽白块"和"拟合直线度"。
- 我们 v121 已有"长链竞争"（防碎片劫持）；v120 有"不可信中线不指挥转向"。
- **判断**：我们的方案不逊色（多了一道"资格闸门"共享）。**宽度上限排除**可以借用到种子评分里（防大环白区被当路）——已有类似机制（学习路宽上限96），**已基本覆盖。**

### 3.3 结论（视觉）

| 项 | 判断 |
|---|---|
| 我们的优势 | 种子海选/长链竞争（防劫持）、两级大津专门化（蓝白）、模型插值补盲、untrusted-guard 等防御性细节多 |
| 我们的短板 | ①无局部自适应阈值（光照适应性弱）②无畸变校正（前瞻失真）③盲区全白的根因未确认 |
| 学什么 | 先等盲区存帧证据；若是阈值问题→局部阈值；否则→畸变校正（P2） |
| 不学什么 | 暂不需要换整体架构（我们的边线+防御体系是适配 TC264 的最优解之一） |

## 四、一句话总结

**环岛：方法论上我们已与国赛同步（视觉状态机 + 保险），差异在"环内看不看得见的时候怎么办"——国赛的清一色答案是"画线穿越"（用几何规则强造中线），这正是我们第3/4轮失败的同款药方；修复方向（盲区注右转+降速）与国赛思路一致，验证了方案的合理性。**

**视觉：我们的栈是"快而专门"（整幅大津+高级防御），国赛的栈是"稳而通用"（局部阈值+畸变校正+形态学）。当前无必要整体迁移；两个候选升级项（局部阈值、去畸变）都已排入队列，等盲区存帧的证据决定优先级。**

| 行动项 | 优先级 | 状态 |
|---|---|---|
| ①环内盲区长失线"画线兜底"（注右转+降速） | **P0** | 方案已备（待批准；对应第3/4轮失败） |
| ②四环双模板（左环识别） | **P0** | 待做（比赛要求 A–D 环全入） |
| ③盲区自动存帧 → 判"全白"根因 | **P0** | **已完成并烧录（v142）** |
| ④局部自适应阈值（若存帧证据支持） | P1 | 备选 |
| ⑤去畸变标定（RUBO 工具链） | P2 | 排队 |
