# v134 大圆环检测器稳健化（2026-10-11 03:54 已烧 HEX D2ED57B1）

## 一、v133 首跑失败诊断（数据+理论齐备）
**现象**：用户录制一段（200样本≈13s），"没进环直接直走过去了"。
**证据链**：
1. 车上回读：`big_ring_enabled=1`（BIG ON 开着）但 **`big_ring_phase=0`（从未离开OFF——连武装都没发生）**；
2. 录制回放：全片搜不到任何"右转注入"签名（若执行过TURN相位，中线会连续=84）→ 状态机全程零动作；
3. `track_fault=MANUAL`（用户手动停车）。
**根因（用合成实验证明）：检测器过度依赖停放拍摄的单帧位置——**
把点3帧水平平移测试：**左移5px 或 右移20px 检测器即失效**（垂直±8行、亮度±15也失效）。
实车行驶时相机与标定位的偏差远超此容差 → 武装从未触发 → 车照常直行。

## 二、v134 修复内容
1. **三个检测器全部稳健化**：以三帧为种子合成 **30个平移/亮度变体**（±30px横向/±8行纵向/±15灰度）
   + 8个真实负样本，PC 端参数搜索（scripts/search_params_v4.py / v5）；
2. **确认逻辑**：2帧连续 → **165ms窗口内≥2次命中**（容忍高速下闪烁）；
3. **点1超时兜底 30s → 8s**（相当于备用方案B的"跑完就关"）；
4. **新增诊断通道 trace_br2**（复用trace_white）：记录每样本 [arm命中|mouth命中|exit命中|phase]，
   下轮记录可直接回读"哪个检测器何时见到什么"。
