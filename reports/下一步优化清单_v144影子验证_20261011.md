## 一、★P0：环内盲区兜底（v144）——已影子验证，待批准

### 数据依据（两个失败配方的双证据）

**run11（失败）**：环内 f100-103 出现"回正帧"（舵 -0.1~-4.8°，速度却冲到 1704）→ f104 进盲区 → **舵冻结在 -4.8°（浅右转）** → 爬行 1.4s 后转不过来 → 丢线停车。

**run12（成功，但险些同样踩雷）**：同一位置 f100-104 同样"回正+高速"（舵 -0.9~-3.3°、速度冲到 **2232**）→ f105 恰好**单帧**闪断（幸运）→ 恢复。**若 f105 是长盲区，就是 run11 重演。**

> 关键洞察：**"环内回正帧 + 紧跟盲区 = 失败配方"**。v143 修好了"速度"，但"舵"仍会冻结在回正后的浅值。

### 方案（+11 行，全部在 big_ring.c/h 内，环岛隔离边界内）

```
LOOP 相位 + 连续 ≥2 帧无有效线 → 注入温和右转合成线：
  f->mid = 94+24 = 118（与左转协调同值）、valid=1、degraded=1
效果：舵不再冻结浅值，改为按合成线温和右转继续绕环；
     线回来（下一帧 valid=1）即停止注入，自然恢复。
单帧闪断不触发（≥2 帧）；TAIL 相位不注入（保守，出环口需直行）。
```

### 影子验证结果（全绿）

| 场景 | 原版 | **影子版（v144）** |
|---|---|---|
| LOOP 盲区 ≥2 帧 | 不注入（mid=-1，冻结浅舵）| **注入 mid=118 + valid=1** ✓ |
| 单帧闪断 | 不注入 | **不注入**（两侧一致）✓ |
| TAIL 盲区 | 不注入 | 不注入（保守设计）✓ |
| v141 左转协调回归 | 118 改写生效 | **118 改写生效**（未破坏）✓ |
| TURN 注入回归 | mid=124 | **mid=124**（未破坏）✓ |
