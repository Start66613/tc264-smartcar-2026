## 操作速查

| 控件 | 功能 |
|---|---|
| **CH1** 方向摇杆 | 转向（自动差速：内轮减速） |
| **CH2** 油门扳机 | 前推=前进；后拉小段=滑行刹车；再拉到底=倒车 |
| **CH4** 三段开关 | 速度档：低 30% / 中 50% / 高 80% |
| **CH6** 按键 | 速度上限 +500（每次） |
| **CH5** 按键 | 速度上限 -500（每次，最低 1200，最高 9000） |

## 安全机制（别误会成故障）

- **软启动**：上电后**先把扳机回中**（松开）才解锁动力 → 防上电窜车
- **失联保护**：遥控关机/断联 **500ms** → 自动停车 + 舵机回中
- 屏幕实时显示：link 状态 / CH1-6 值 / gear / cap / pwm
