## 三、速度剖面发现（新通道首次出数据）

### 3.1 两次"急刹到近停"事件（最值得关注）
| 事件 | 帧 | 过程 |
|------|-----|------|
| A | 159-168 | 盲闪(R口) → 全舵右 + 中线右扫 → **速度 1020→524→44→88→168→184→280→368→612→948→1020** |
| B | 214-221 | 盲闪(R口) → 全舵右 + 中线右扫到 127(画面最右) → **速度 1020→680→200→20→24→92→200→392→448→608→864** |

两处都是：**环口区域 → 全力制动力（-480/样本=斜率上限）→ 掉到近停（pwm 20-44）→ 再全油门爬回**。
这就是实车"顿挫/一冲一顿"的来源候选（帧 161-168、215-221 各约 0.5s）。

机制推断（未验证）：环口相位下降速目标（260）+ 实际车速仍高 → 误差项把输出拉到底 → 刹过头 → 再补。

### 3.2 全场速度分布
- 全速（显示顶格 1020，实际≥1020）：374/721 ≈ 52%
- 中低速段（曲线降速）：多次 500-990 区间，最长 36-37 样本（2.4s）持续降速
- 近停：2 次（上面的事件 A/B）

### 3.3 ⚠️ 量程 bug（已修，下轮生效）
这轮记录用的 /4 换算（上限 1020）不够——巡航 PWM 就顶格了，所以"全速"只能确认 ≥1020，分不清 1100/1380。
**已修复：/4 → /12（上限 3060），并已重烧（HEX 6E7837B2）。** 下轮记录速度数据会完整可分辨。
