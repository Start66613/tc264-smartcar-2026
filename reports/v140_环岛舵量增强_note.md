## 一、用户反馈与本次改动
反馈：v139 后**不再直行（方向正确了）**，但"**环岛内打舵角度不够 → 脱道**……会打弯但是打的弯度不够"；
并要求：环岛所有逻辑单独处理、环岛关闭后不影响正常行车、**界限写清楚**。

改动（一处概念「环岛舵量增强」，3 个文件）：
1. `track_core.h`：VTFrame 增加 `steer_boost_pct` 字段（默认 0）；
2. `track_core.c` vt_step：`if(v->special_route && v->steer_boost_pct>0) turn *= 1+boost/100`（仅模块驱动时放大）；
3. `big_ring.c/h`：新增参数 `BR2_STEER_BOOST_PCT = 50`（+50%），在 TURN/LOOP/STRAIGHT 写入；
   TAIL 暂不增强（出环后走直行，暂不需要）；BIG OFF / DONE 不写 → 恒 0。

**为什么放大 50% 起步**：环内实测需求高，但过强会导致贴内沿/画龙；先 +50%，跑一圈按手感调
（一行参数：不够→60/80，过冲→30/40）。
