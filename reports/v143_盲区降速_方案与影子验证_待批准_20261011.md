## 二、根因定位（代码级，已用 host 复现）

**位置**：`track_core.c` 速度 PI 输出段（L811-826）

**机制链**（盲区帧: valid=0 + all_white=1 + degraded=1）：
1. 盲区帧**不进入**"丢线降速路径"（L696 的条件明确排除 all_white 帧）→ 无强制降速；
2. 走常规路径：target 被 degraded 压到 320（合理），但**速度 PI 照常运行**：
   `output = target*3 + err*2.5 + integral`，其中 `err = target - 实测速度`；
3. **当车轮被挡/打滑/反馈偏低时**（盲区里车正撞向障碍），err 持续为正 → **积分每拍累积** → 输出每拍 +34 → **PWM 从 648 一路升到 1980/2820**（"车轮越被挡，油门越加大"）；
4. 车在盲区里被"油门推着"横冲 —— 这就是"盲飞加速"。

**host 复现**（合成序列：正常巡航 → 36 拍全白盲区 + 低反馈）：原版 pwm 1380 → **2609**（+89%），与实车数据完全同型。✓

## 三、修复方案（影子补丁，+15 行纯新增）

**改动点**：`track_core.c` 仅一处功能块 + 一个计数（`track_core.h` 加 1 个字段）：

```c
/* ① new_frame 块内：盲区计数（连续无有效线，含全白） */
if(!v->valid){if(c->blind_frames<100000u)c->blind_frames++;}else c->blind_frames=0;

/* ② 速度输出段（差速计算后、PI 循环前）：盲区降速 */
if(!v->valid && c->blind_frames>=2u){
    unsigned crawlp=(unsigned)(VT_LOST_CRAWL*3);
    for(i=0;i<2;i++){
        c->target[i]=(uint32_t)VT_LOST_CRAWL;
        if(c->pwm[i]>crawlp+160u)c->pwm[i]-=160u;   /* 每拍-160，快速下压 */
        else if(c->pwm[i]>crawlp)c->pwm[i]=crawlp;  /* 压到爬行档止 */
    }
    c->updates++;
    return;   /* 不走 PI —— 杜绝积分反向加油 */
}
```

**设计要点**：
- **触发阈值 ≥2 拍**（130ms）：单帧闪断**绝不触发** → 三个成功轮（环内单帧失线）行为**逐帧不变**；
- **下压力度**复刻现有"丢线降速"的成熟参数（每拍 -160、目标 crawl=450），不引入新常数；
- **转向不动**：盲区时保持现有"冻结/保持"行为（这是另一项，将来如需再叠加"环内盲区温和右转"，本次不做——一次只动一处）；
- **线回来立即恢复**：计数清零，PI 接着跑，无迟滞。
