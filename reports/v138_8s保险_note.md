# v138：环岛模块"8 秒强制关闭"保险（用户方案，2026-10-11 07:28 已烧 HEX 9FF057B9）

## 一、是什么（用户原话）
「防止环岛模块没关闭的小保险……如果开跑后八秒内环岛模块还没关就强制关，不影响后面的，
这个八秒是我用手机计时得出来的。如果环岛八秒内关了就不执行保险。」

## 二、实现（只动 big_ring.c / big_ring.h 两处）
- `BR2_GUARD_MS = 8000u`；
- 计时起点 = 本次复位后**第一次"开跑"**（controller running 的 0→1，即发车瞬间）；
- 到点判断：若模块**尚未 DONE**（无论 OFF/ARMED/TURN/LOOP/STRAIGHT/TAIL）→ 强制进入 **DONE**
  → 静默、零注入、不再武装（与自然跑完后的状态逐位一致，**不影响后续任何巡线**）；
- 若 8s 内已自然 DONE → 保险**不动作**。
- 复位条件：长按 P20.6 重开 BIG ON/OFF、或重新发车（epoch 复位）→ 保险重新计时。

## 三、与正常跑的关系（为什么日常不会误触发）
实车记录（0504/0510）：模块从"开跑"到自然 DONE ≈ **7.8~8.0s**（128~129 个采样×65ms）。
8s 阈值 = 用户手机实测的正常时长 → 正常一跑保险保持静默；只有"卡住/异常慢"才会触发。
> ⚠️ 已知边界：若某次跑得明显更慢（车被按着发车、堵车、电量低），到 8s 时模块可能还在环内
> → 保险会把模块提前关掉（环内左转禁令随之解除）。如实车看到这种误伤，把 `BR2_GUARD_MS`
> 调到 9000~10000（一行）即可，其余不用动。

## 四、怎么在记录里看到保险触发
trace 的 b2 列 = (hits&7) | (phase<<3)。正常结束前会短暂经过 5（TAIL）；
**若某帧 b2 的相位部分直接跳到 6（DONE）且时刻≈开跑后 8s，就是保险触发**。
