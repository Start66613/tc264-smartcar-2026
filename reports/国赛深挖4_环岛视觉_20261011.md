## 〇、本轮"新增事实"清单（一句话版）

1. **CQU 角点检测有两套并存实现，`[0]/[1]` 语义完全相反。** 生效版 `findp()`（L1426-1560，`findline.c:1010` 每帧调用）写 `leftup[0]=列、leftup[1]=行`；另一版 `drawp()`（L2095-2141，`findline.c:1011` 被注释）写 `leftdown[0]=行、leftdown[1]=列`。环岛状态机 `Huandaochuli_*` 里到处是 `connect_line(Findp.leftup[0],Findp.leftup[1],…)`——**当前只对 `findp()` 自洽；一旦有人"启用 drawp 试试"，行/列会静默互换**。
2. **CQU 的 `Monotonicity_Change_Left/Right`（L2011/L2049，"前5后5最大 = 圆弧中点/出环角点"）是死代码**，只在被注释的 `drawp()` 内调用；生效版是 `findp()` 内联的 L1505-1558，**多了一条 `leftline[i]<=80` / `rightline[i]>=80` 的左右半区约束**。`blackbox()`（L2082）、`lostupdown()`（L1135）、`Find_Left/Right_Up/Down_Point()`（L1870-2003）、`findline_left_right()`（L1031）**全部无调用者** → CQU 的 `findline.c` 2189 行里，**约一半是历史残留**。（与深挖3 NEUQ"拟合评分死代码"同款现象。）
3. **CQU 角点判据 = "边界前后行差的不对称"**：上方连 3 行平坦（`|Δ|≤5`）∧ 下方 2~4 行突变（`≥5 / ≥8 / ≥15`）→ 返回**角点所在行号**。**我方（`track_core.c:308`）只做 `|Δy|>=7` 计数 ≥2 → 布尔标志、无行号、无方向性。**
4. **`connect_line(x1,y1,x2,y2,type)` 有一个真实陷阱**（L1562-1584）：`if (y1 > y2) { 只交换坐标、不画线 } else { 才画 }` → **当 `y1 > y2` 时函数是空操作**。CQU 靠调用方保证 `y1<y2` 才没暴雷；`blackbox()` 传 `leftdown[1]`（行号，可能 >110）就是潜在雷点。
5. **SJTU 巡线根本不做整幅二值化。** `findline_lefthand_adaptive / righthand_adaptive`（`imgproc.c:247-330`）在**原灰度图**上，用"**每走一步重算的 block×block 局部均值 − clip_value**"当阈值走迷宫。→ `adaptive_threshold()`（`imgproc.c:50-72`）整幅二值化**只用于调试绘制**（`main.c:470-479`，在 `if(gpio_get(DEBUGGER_PIN))` 里）。**这是我方"盲区全白"根因的直击答案。**
6. **SJTU 把边线点做"像素→物理"映射后再算角度**：`rpts0[i] = (mapx[y][x], mapy[y][x])`（点级查表，`main.c:548-557`，表在 `camera_param.c`：996 行 K/D 内参 + H 单应 + `mapx/mapy[240][376]` 浮点表）。**角点判据是物理角度**：`conf = |a[i]| − (|a[i−k]|+|a[i+k]|)/2`，Y点 30°~65°、L点 70°~140°（`main.c:602/607`）。
7. **SJTU 中线 = 单边线沿切线法向平移路面半宽**（`track_leftline / track_rightline`，`imgproc.c:612-635`，`dist = pixel_per_meter*ROAD_WIDTH/2`）。**这正是我方环内缺的"由单侧可信边线合成中线"能力的干净实现**——且**不需要真实对侧边线**、**弧上比逐行水平宽度更准**。
8. **SJTU 环岛 `circle.c` 是 10 态**，判据 = **边线物理长度（丢线 cm 数）+ L角点沿线位次 + 编码器打表 1/4 圆**；**源码内留有作者自标注缺陷**（L57-58 / L110 / L129："应修正为右线为转弯无拐点"）。
9. **进环判据三家一致**：CQU `leftdown_flag && lcenter_flag && right_trueshortflag && !left_trueshortflag`；SJTU `Lpt0_found && !Lpt1_found && is_straight1`（`circle.c:25`）；HammerTa `CrossRow_L>0.9 && CrossRow_R<0.8 && R_S<0.4`。**共性 = "单边角点/开口 + 对侧长直道"**；我方现在是"固定像素行带模板"，**独此一家**。

### 2.2 ★★ 迷宫巡线 = 局部自适应阈值（`imgproc.c:247-330`）—— 本报告最重要的一条

```c
void findline_lefthand_adaptive(image_t *img,int block_size,int clip_value,int x,int y,int pts[][2],int *num){
  int half=block_size/2, step=0, dir=0, turn=0;
  while(step<*num && half<x && x<img->width-half-1 && half<y && y<img->height-half-1 && turn<4){
    int local_thres = 0;
    for(dy=-half..half) for(dx=-half..half) local_thres += AT(img, x+dx, y+dy);  // L255-258 ★ 每步重算
    local_thres /= block_size*block_size;
    local_thres -= clip_value;                                                   // L261 ★ 偏移
    int front_value     = AT(img, x+dir_front[dir][0],      y+dir_front[dir][1]);
    int frontleft_value = AT(img, x+dir_frontleft[dir][0], y+dir_frontleft[dir][1]);
    if     (front_value     < local_thres) { dir=(dir+1)%4; turn++; }            // 前方黑 → 右转(左手法)
    else if(frontleft_value < local_thres) { 前进一步;  记录点; turn=0; }        // 前左黑 → 直行
    else                                   { 走前左; dir=(dir+3)%4; 记录点; }    // 都不黑 → 左移转向
  }
  *num=step;
}
```

**要点（逐条）**：
- 阈值 = **当前位置 `block×block` 邻域均值 − `clip_value`** → **局部对比度**，与整幅亮度无关。
- `AT_CLIP`（L5）对越界坐标做 clamp，**不返回 0**，避免边缘假黑。
- `turn<4` 限制"原地连续转向 4 次以上即停"（死循环保护）。
- **`adaptive_threshold()`（L50-72）整幅二值化在主流程里没被用**，只出现在 `main.c:470-479` 的调试绘制分支。

> **这就是我方"盲区全白"的根因答案。**
> 我方 `cam_otsu_two_level()`（`cam_image.c:152-244`）**是全局阈值**：直方图从 `cam_gray[28][0]` 起（`cam_image.c:351`，即只用 y≥28 统计），一级 Otsu 后若亮类占比 >62% 就对亮类再跑一次。**这套两级设计已经比 NEUQ/HammerTa 的"大津+偏置"强**，但**本质上仍是"整帧一个数"**：
> - 场景：**环岛内壁大面积白 + 强光/白墙** → 亮类占比破 62% → 触发二级 → 若亮类内部双峰不成立（`gmax-gmin<12`）就**退回一级 t1**，而一级 t1 只分出了黑胶带 → **蓝底与白路一起判白**（`cam_image.c:137` 的实测注释正是这个现象：一级 Otsu=169，y=90 行"白段"横跨整幅）。
> - SJTU 的局部均值**没有"整帧占比"这个全局量**，天然免疫。

**可学 AA（P0，最小改动版）**：**不换整套迷宫巡线**，只给我方逐行白段提取（`vt_analyze` 第 1 遍，`track_core.c:161-…`）**加一路"局部对比度"确认**：对每行的候选白段，计算
`局部阈值 = (段内均值 + 段外左右 N 像素均值)/2 − 裕量`，
只有**段内均值 ≥ 局部阈值 + 裕量**才承认该白段（或按 SJTU 直接比"像素 vs 邻域均值−clip"）。
→ 这样**保留我方逐行链式架构**（深挖3 §1.4 已论证逐行链更适合有岔口的赛道），只在**"全局阈值失效帧"**上多一层局部守卫。**风险低，直击根因。**

### 2.3 去畸变 = 点级查表，不是图像级 remap

- `imgproc.c::remap()`（L210-226）是**图像级**去畸变（对每个像素查 `mapx/mapy` + 最近邻取整）——但它**不是主流程用法**。
- 主流程是**点级**（`main.c:548-557`）：只对 ~几百个边线点查一次表。表来自 `camera_param.c`（996 行）：`K[3][3]` 内参、`D[4]` 畸变、`H[3][3]` 单应、`mapx/mapy[240][376]` 浮点表 + `invx/invy` 反向表（`camera_param.h:7-13`）。

**可学 AA（P3）**：若我方要做去畸变，**照点级做法**（只在边线点链上查表），**不要整幅 remap**（240×376 每帧开销大）。但**前提是先量我方 MT9V03X+短焦镜头的实际畸变**——目前**未测**。**暂不紧迫。**

### 2.4 ★ 中线 = 单边线法向平移路面半宽（`imgproc.c:612-635`）

```c
void track_leftline(float pts_in[][2],int num,float pts_out[][2],int approx_num,float dist){
  for(int i=0;i<num;i++){
    float dx = pts_in[clip(i+approx_num,0,num-1)][0] - pts_in[clip(i-approx_num,0,num-1)][0];  // 切线
    float dy = pts_in[clip(i+approx_num,0,num-1)][1] - pts_in[clip(i-approx_num,0,num-1)][1];
    float dn = sqrtf(dx*dx+dy*dy); dx/=dn; dy/=dn;
    pts_out[i][0] = pts_in[i][0] - dy*dist;    // 左线  → 法向右偏 half-width
    pts_out[i][1] = pts_in[i][1] + dx*dist;
  }
}
```

调用侧 `dist = pixel_per_meter * ROAD_WIDTH / 2`（`main.c:584`）→ **中线 = 可信单侧边线整体向路内平移半路宽**。

**与我方比对**：

| 维度 | SJTU | 我方 v142 环内（`big_ring.c` LOOP/TAIL） | 我方逐行贴边（`track_core.c:65-95`） |
|---|---|---|---|
| 做法 | **沿切线法向平移半宽** | **只夹中点**（`big_ring.c:175-181`：`mid<80 → 118`） | 单边贴边时用**学习路宽**补另一侧（**水平**补） |
| 依赖真实对侧边线 | ❌ 不需要 | — | ❌ 不需要 |
| 弧上精度 | **高**（法向跟着弧转） | 无 | 中（水平切在弧上有误差） |
| 适用 | 任意单侧可信边线 | 环内 | 环内/急弯 |

**可学 AA（P1，与深挖3 H1/H2 合流）**：给 `big_ring` 的 **LOOP/TAIL** 加"**法向平移中线**"——用环内那一侧**可信边线的点链**（我方 `track_core` 已维护 `t->left[]/right[]` 逐行点），沿其切线法向平移 `学习半宽/2` 生成 `mid` 注入。
→ 相对 22届的"逐行**水平**宽度合成（`Width_Max+11`，深挖2 §3.2）"，**法向平移在弧上更准**（环内边界是圆弧，水平切 ≈ 真半宽但有弧误差；法向平移是精确的"等距偏移曲线"）。
→ **建议：先实现"法向平移"，若仍不够再叠加"行宽先验"（22届式）；两者可"或"计。**

### 2.5 角点 = 物理角度二阶差分 + NMS（`main.c:590-632`）

```c
float conf = fabs(rpts0a[i]) - (fabs(rpts0a[im1])+fabs(rpts0a[ip1]))/2;   // L599 ★ 二阶差分
if(!Ypt0_found && 30./180.*PI < conf && conf < 65./180.*PI && i < 0.8/sample_dist) {...}  // L602 Y点
if(!Lpt0_found && 70./180.*PI < conf && conf < 140./180.*PI && i < 0.8/sample_dist){...}  // L607 L点
if(conf > 5./180.*PI && i < 1.0/sample_dist) is_straight0 = false;                       // L612 长直道
```

- `local_angle_points`（`imgproc.c:576-594`）= 用 `atan2` 算 i 点前后 ±k 个点的**转角**；
- `nms_angle`（`imgproc.c:597-609`）= **非极大抑制**（邻域内不是最大则置 0）→ **天然抗单点噪声**（只有局部最强才被保留）；
- Y 点二次检查（`main.c:634-640`）：两 Y 点**距离 ≈ 0.45m ± 0.15m**（物理尺度！）才算真 Y 点。

**可学 AA（P2）**：SJTU 的"**NMS + 二阶差分**"从机制上解决了我方 1.3-1 的"相邻抖动骗过计数"问题——`NMS` 保证只有"局部最尖"的那一点算角点。
→ **与我方 1.3-1 的"对称性前置"二选一即可**，**不必上物理量纲**（我方没有 `pixel_per_meter` 标定，上物理量纲成本高）。**推荐先做"对称性前置"（成本最低）。**

### 2.6 环岛状态机 `circle.c`（10 态）+ 作者自认缺陷

**10 态**（`circle.c:5-15`）：`NONE / LEFT(RIGHT)_BEGIN / LEFT(RIGHT)_IN / LEFT(RIGHT)_RUNNING / LEFT(RIGHT)_OUT / LEFT(RIGHT)_END`。

| 迁移（左环） | 条件（源码） | 行号 |
|---|---|---|
| NONE → LEFT_BEGIN | `circle_type==NONE && Lpt0_found && !Lpt1_found && is_straight1` | L25（`check_circle`） |
| LEFT_BEGIN → LEFT_IN | 左线丢线计数 `rpts0s_num < 0.2/sample_dist` 后又 `> 1.0/sample_dist` 且丢线次数 >2 → `have_left_line>1` | L41-50 |
| LEFT_IN → LEFT_RUNNING | `rpts0s_num < 0.1/sample_dist` **或** `编码器增量 ≥ ENCODER_PER_METER*(π/2)` | L57-58 |
| LEFT_RUNNING → LEFT_OUT | `Lpt1_found && Lpt1_rpts1s_id < 0.4/sample_dist`（外环拐点在 40cm 内） | L64-68 |
| LEFT_OUT → LEFT_END | `is_straight1`（右线为长直道） | L75-77 |
| LEFT_END → NONE | 左线丢线计数 `>0.2/sample_dist` 后再 `>1.0/sample_dist` 且丢线 >3 | L84-88 |

`run_circle()` 每态设 `track_type = TRACK_LEFT / TRACK_RIGHT` —— **环岛本质就是"切换要跟哪一条边线"**。

**★ 作者自标注缺陷（源码原文）**：
- L56-58：`//编码器打表过1/4圆   应修正为右线为转弯无拐点`
- L110：`//编码器打表过1/4圆   应修正为左线为转弯无拐点`
- L129：`//左长度加倾斜角度  应修正左右线找到且为直线`
- L119：`//外环存在拐点,可再加拐点距离判据(左L点)`
→ **SJTU 的环岛本体是"开环里程 + 单侧线跟踪"，作者自己标了 4 处待修正。** 说明**这套环岛的成熟度并不比 22届/CQU 高**。

**结论（具体）**

1. **【保持我方，不学】编码器打表。** SJTU 用"走过 π/2 米"判断"已过 1/4 圆"是**纯开环里程**，打滑/坡道/急加速都会失准；我方 `big_ring` 用"检测器 + 时间兜底（`BR2_TAIL_TO_MS=8000`）"更简单可靠。**保持我方 8s 时间兜底。**
2. **【可学 AA（P2，认知级）】门限用"物理长度"而非"像素行数"。** SJTU 的门限全是 `x / sample_dist` 形式（**把像素点索引÷点间距 = 物理长度**），换分辨率/换安装角**不用重标**。
   → 我方 `br2_detect_*` 的 `y41-56 / y26-48 / y18-28`、`rs[0]>=140 / >=162 / >=166` 全是**像素硬编码**（深挖3 §2.6 已指出"位置锁定"）。**建议：把 br2 的门限先换算成"行号占比 + 离底行像素数"两组相对量，再落到参数**——**换标定只需改一个比例，不用重搜 30 个变体**（`scripts/search_params_v4/v5.py` 的工作量可复用）。
   - 注意：**SJTU 自身也是"物理量纲 + 硬编码阈值"混用**（`ROAD_WIDTH`、`pixel_per_meter` 仍是标定量），**只抄"相对化"的思想**。
3. **【可学 AA（P2）】"环岛 = 切换跟哪条边线"的建模方式。**
   SJTU 把环岛化简为 `track_type = LEFT/RIGHT`（跟哪条边线），**不需要在环内合成边界**——因为它的中线本来就是"单边线法向平移"（§2.4）。
   → 这与我方"环内只夹中点"是**同一族思路的退化版**。**升级到法向平移（§2.4）后，我方也能做到"只切边线、不合成"**——比 CQU/22届的"画线/钉边界"更轻。
