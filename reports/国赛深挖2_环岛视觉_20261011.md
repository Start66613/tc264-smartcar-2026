## 〇、本轮"新增事实"清单（一句话版）

1. **我方 v122 早就有 CQU 式的偏航阻尼**（`track_core.c:668-676,744`，注释直接写着 "CQU-style yaw-rate damping"）——**普查版的"CQU 陀螺分段是备选、暂不学"结论需要修正：阻尼本身已在用，差的是"环内才加强"和"盲区不丢阻尼"。**
2. **CQU 环岛是 10 阶段（`hdflag` 0–9）+ 陀螺积分门限 10°/45°/64°**，且**每个阶段用 `connect_line()` 直接合成一条边界线**（不是夹中点）。我方环内只夹中点、不合成边界——这是"看 vs 画"差距的**精确落点**。
3. **22届 `Width_Max[i]+11` 的意图 = 以可信的近侧边线为基准、按"期望宽度+11"合成远侧边界**，让车贴环内壁走；`Width_Max[]` 是逐行期望**宽度**表（底部 50）。
4. **22届的 `Annulus_Delay[4]={120,130,120,130}` 毫秒表在决赛版是死代码**（`Annulus_DelayMs++` 被注释），实际退出靠视觉状态机 + `Annulus2_Delay=15` 最短保持。**"预设环序"这点被作者自己弱化了。**
5. 22届另有**大小环判别**：补线区间内黑点数 `10<Annulus_Nums<35` → `Annulus_Small=1`。我方无此区分。

## 一、CQU `control.c` —— "误差 − 陀螺角速度"阻尼（目标 #1）

### 1.1 原文取证（带行号）

**核心公式在 `ServControl1()`（L174–202）**：

```c
void ServControl1(float err)                         // L174
{
    Error = (err - CarAngle.Yawrate) / 10;           // L176  ★★★ 就是这里
    ErrorFifo 右移，ErrorFifo[0]=Error;              // L177-179
    ErrorInteger += ErrorFifo[0];                    // L181  （10拍积分，函数内不清零）
    ErrorDtTemp[0] = ErrorFifo[0]-ErrorFifo[3];      // L189  （3拍差分）
    InOut = ServPID1.P*ErrorFifo[0]
          + ServPID1.I*ErrorInteger
          + ServPID1.D*(ErrorDtTemp[0]*0.8 + ErrorDtTemp[1]*0.1 + ErrorDtTemp[2]*0.1);  // L192-193
    OutPut = OutTemp[0]*0.8 + OutTemp[1]*0.2;        // L199  （输出2拍滤波）
    OutPut = OutPut*1.2;                             // L200  （量级匹配）
}
```

**`ServControl()` 最终出舵（L134–170）**：

```c
if(USE_GYRO){                                        // L136
    pout = pout0 - ServPID.P * OutPut;               // L137
    dout = (OutPut + lastError) * ServPID.D;         // L138  ← lastError 疑似从不更新（见 1.4）
    pout -= dout;
} else {                                             // 位置式 PD：pout0 - P*err - D*(err-lastError)
    pout = pout0 - ServPID.P*Findline.err[0];        // L142-144
}
限幅 ±delt_pout_max(=85)，pwm_set_duty;              // L160-169
```

**何时切换（`ServControl_mix()` L103–114）**：

```c
if(right_hdflag>=1 || left_hdflag>=1){               // L105  ★ 只要进环岛任意阶段
    ServControl1(Findline.err[0]);                   // L107  陀螺级联
    ServControl();
} else {
    fuzzy_ServControl(Findline.err[0]);              // L112  环外走模糊
}
```

**模糊路（环外）也扣 yawrate**（L117）：
```c
pout = pout0 - Fuzzy_P(...)*Error - ServPID1.P*((Error - CarAngle.Yawrate)/10);
```

**`Yawrate` 的来源与死区**（`gyroscope.c`）：
```c
CarAngle.Pitchrate = Angle_Speed;                    // L69
if(abs(CarAngle.Yawrate)<0.5) CarAngle.Yawrate=0;    // L71-72  ★ ±0.5 死区
CarAngle.TureYawrate = 2.25*Yawrate/cos(Pitch*PI/180); // L74  倾斜补偿（伺服用的是未补偿的 Yawrate）
```

**一句话读懂 CQU 的公式**：
> 输入不是视觉偏差，而是 **`(视觉偏差 − 角速度)/10`** —— 角速度作为**减项直接串进误差**。这不是"外环角速度内环角"的真串级，而是**速率前馈阻尼**：车正在按角速度转，就认为这个偏差会被自己转掉一部分，于是**提前削舵**。配套：10 拍积分抑制稳态差、3 拍加权差分抗噪、输出 2 拍滤波，增益 `P=1.8 / D=0.2`（`PID_init L77-78`）。

### 1.2 与我方比对（我方**已有**同款，v122）

我方 `track_core.c`：

```c
/* v122 (CQU-style yaw-rate damping): CQU injects (err - yawrate/10) into
 * the steering PID; we subtract a bounded scaled yaw rate from the error ... */
if(imu_valid){ gd = (float)gyro * (float)VT_GYRO_DAMP_K;            // L673
  if(gd>VT_GYRO_DAMP_MAX) gd=VT_GYRO_DAMP_MAX;                      // L674
  if(gd<-VT_GYRO_DAMP_MAX) gd=-VT_GYRO_DAMP_MAX;                    // L675
  gd *= VT_GYRO_DAMP_SIGN; }                                        // L676
...
if(v->mid>=0) e -= gd;   /* v122: yaw-rate damping (only when this frame had a line) */ // L744
```

常量（`track_core.h`）：`VT_GYRO_DAMP_K = 1/30000`，`VT_GYRO_DAMP_MAX = 0.06`，`SIGN = +1.0`。
`gyro` 来历：IMU660RA 原始 LSB，去零偏 + 4 拍滑窗均值（`cpu0_main.c:3750-3764`，无死区）。

| 维度 | CQU | 我方 v122 |
|---|---|---|
| 形式 | `(err − Yawrate)/10` 串进误差 | `e -= gyro·(1/30000)`，有界 ±0.06 |
| 作用时机 | **仅环内**（`hdflag>=1`）走此路；环外走模糊（也含 yawrate） | **全局常开**（环外直线也扣） |
| 生效门控 | 环内必生效 | **`if(v->mid>=0)` 才生效** ← 见 1.3 |
| 量纲/死区 | deg/s，±0.5 死区 | 原始 LSB，无死区 |
| 饱和行为 | 不显式饱和（增益本身小） | 硬饱和 0.06（≈5.6px 归一误差，约 110dps 触顶） |

### 1.3 结论（具体：我方在什么场景会出什么问题）

1. **我方阻尼在"最需要它的帧"上恰好失效。**
   门控是 `if(v->mid>=0)`（L744）——只在本帧有中线时才扣阻尼。而**环内盲区 / 全白 / 丢线帧正是 `mid<0`**（`big_ring.c` 只在 TURN/STRAIGHT 注入 `mid`，LOOP/TAIL 多数帧不注入）。→ **车在环里转得最猛、图最白的那几帧，偏航阻尼被整个丢掉**，只剩 "`e` 保持上一帧 + 舵量保持"（`track_core.c:735-736, 707`）。这恰是第 3/4 轮"长失线飞出"的机理之一。
   **可学 AA**：把阻尼门控从 `mid>=0` 改为 **`imu_valid && steering_initialized`**（有历史转向基准即可施阻尼），盲区帧用 `last filtered_error` 继续扣 `gd`。这是**一行级**改动，风险低、直击环内盲区。

2. **CQU 是"环内才加强"，我方是"全局一刀切"。**
   CQU 环外仍有 yawrate 项但增益低（模糊 P 小）；我方 `K=1/30000、MAX=0.06` 全局施加。**可学 AA**：给环内 phase（`VT_RING_*` 或 big_ring LOO{P,TAIL}）单独放大 `VT_GYRO_DAMP_K`（或提高 MAX），环外保持现值——即"环内加强版"，无需引入 CQU 的整套串级。

3. **死区**：CQU 有 ±0.5 死区（`gyroscope.c:71-72`）抑制静止/低速抖动；我方无。**可学 AA**（廉价）：`|gyro| < GYRO_DEAD` 直接置 0，减少直道微抖带来的抖动。

4. **（顺带发现，非我方问题）CQU 自身疑似 bug**：`ServControl()` L138 用 `lastError`，但 `ServControl1()`/`fuzzy` 里的 `lastError=...` 赋值在 `fuzzy` 中被注释掉（L120），`ServControl1` 里根本没有 `lastError` 赋值 → `lastError` 恒为初值 0。**CQU 的 D 项在 `USE_GYRO` 路实际退化成 `OutPut*D`**。→ 说明**外部代码不能照抄**，我方"照原理自研 + 记录证据"的纪律是对的。

### 2.3 结论（具体）

1. **差距精确定位**：CQU 在 4→7（陀螺推进期，环内最盲区）**不是"看点"，而是"画线 + 钉边界"**。我方 `big_ring.c` 在 LOOP/TAIL 只有：
   ```c
   if(f->mid>=0 && f->mid<80) f->mid = 94+24;   // L175-176,180-181：大左转才改右转
   ```
   **只做"中点夹取"，从不生成边界线**。一旦环内视觉把"被环口破坏的远壁"读成真边界 → 我方 `mid` 被拉向环外 → 飞出；CQU 则用 case4 直接钉死左线，`mid` 被结构性地压在左侧。
   **可学 AA（增量、最小版）**：给 `big_ring` 的 LOOP/TAIL 加"**若连续 N 帧 mid 都落在左半区（<80）→ 进入 case4 式钉边模式**"：由 `big_ring` 向 `track_core` 下发一个"贴左/贴右"标志，`track_core` 在逐行阶段把对应侧边线钉到固定列、再算 mid。**先做"贴左"单侧版本**（因为是右环反向绕），验证后再镜像。

2. **陀螺可当"信任判据"**：CQU 用累积转角 10°/45°/64° 卡阶段——视觉暂时瞎了也知道"转到哪了"。我方 `big_ring.br2_process` **已经收 `imu_valid` 和 `yaw10` 参数，但在 L115 被 `(void)` 丢弃**。
   **可学 AA**：把 `yaw10`（进环后累积转角）接进来做**阶段进度兜底**：点2 已过 + 累积转角 ≥ 阈值 → 即便 `br2_detect_exit` 未命中，也推进到 TAIL/DONE。这正好把上轮 P0 行动项（"盲区注右转+降速"）**从"纯时间兜底"升级为"时间+角度双兜底"**。

3. **保持不学**：`connect_line` 的**硬编码坐标**（如 `(55,30,5,115)`）是**针对该车该赛道手调的一次性标定**，换车/换场即废——**不可照抄坐标，只抄"阶段→合成边界"的结构**。

## 三、22届决赛 `handle.c :: Annulus2_Handle`（目标 #2）

> 函数实际范围 **L247–416**（原题标 L247–480 含后续 `Image_Para_Init`）。配套 `Annulus_Control/Annulus2_Control` L204–240。

### 3.1 进环检测（视觉触发）

- **简单版**（L607-638）：`Width_Real[i+2]>30 && i<50 && 左右 Add_Flag && Add_Start && !Add_Stop` 且宽度突变满足 `Width_Real[i+2] > Width_Real[Add_Start_Max]`、同宽且四行内左右线变化 ≤5 → 判宽度突变。
- **含起跑线版**（L490-601）：先过 3 段黑白交替（起跑线检测）→ `Starting_Line_Time==3` → 计补线区间黑点数 → 触发 `Annulus2_Control()`。

- **进环登记**（`Annulus2_Control` L225-240）：`Annulus_Right=Annulus_Count[Annulus_Times++]`（取**预设左右序**）、`Annulus_Mode=1`、`Annulus_Flag=1`。

### 3.2 ★ 环内补线：`Width_Max[i]+11` 的意图（L285–304）

```c
for (i = 59; i >= 15;) {

            Right_Add_Line[i] = Left_Add_Line[i] + (Width_Max[i]+11);  // L290 ★合成远侧(右)
            Right_Add_Line[i] = range_protect(...,0,79);

```

**`Width_Max[61]` 定义（L24）**：逐行期望**宽度**表，远行 5 → 近行 50（`{5×20, 12,12,15,15,… ,48,48,50,50}`，第 60 项缺省 0）。
**首行若已补线，`Width_Min=60`**（L266-269）——抬高下限，防后续窄读数把环口误判成正常收窄。

**意图拆解（用户问题的答案）**：
> 环口处**远侧边线被环壁/外场破坏、不可信**，而**近侧边线（内侧环壁）可信**。于是**不采信远侧真线**，改以近侧边线为基准，按 `期望宽度 + 11` 合成一条远侧边界。`+11` 让合成宽度**超过任何正常宽度**，于是 `Mid_Line` 被**结构化地固定在"近侧边线 + 半宽偏移"处**——**车贴着环内壁、以恒定横向偏移绕环**，完全不被环口的干扰边线带偏。
> 即：**"宽度上限"不是限制，而是一个"合成远侧边界的固定宽度值"**；名字叫 `Width_Max` 但用法是"期望宽度基准"。

**与我方比对**：我方 `big_ring` 在 LOOP/TAIL **不做任何逐行边界合成**，`track_core` 的逐行阶段虽已有"学习路宽上限 96"（普查版提过），但**只在"种子评分"里排除过宽白块，没有"以近侧边线合成远侧"这一步**。→ 环口干扰边线仍可能进入 `mid` 计算。
**可学 AA**：把 22届的"近侧定基准 + 期望宽+裕量合成远侧"搬到 `track_core` 的逐行阶段，**仅在环内标志置位时启用**（`frame.special_route` 或新增 ring 标志），用现成的学习路宽做 `Width_Max`。这是"画线穿越"的**逐行软版本**，比 CQU 的整条钉死温和，风险可控。

### 3.3 退出判定 —— `Annulus_Delay` 毫秒表的真相（重要辨析）

```c

**但计数被禁用**（`App/App/MK60_it.c`）：

```

→ **结论（修正普查版印象）**：`Annulus_Delay` 表（120/130/120/130，"4 环预设时长"）**在决赛版是死代码**，"毫秒倒计时退出"**未启用**。实际退出是**纯视觉状态机**（见 3.4）+ `Annulus2_Delay=15` 的**最短保持**（进 4 态时置 15，递减到 0 才允许回 0 态，防误判提前退环；注释写"最少延时 1s"，实际节拍取决于 `MK60_it` 中断周期，源码注释与节拍不完全自洽）。
**`Annulus_Count[4]`（预设左右序）**由发车按键 PTE0–2 设定（`System.c:236-256`），**只用于决定"期望是左环还是右环"**，不再用于计时退出。

### 3.4 出环状态机 `Annulus_Mode`（L331–415）

| 迁移 | 条件（左环） | 行号 |
|---|---|---|
| 1→2 | 底行需补线（`Right_Add_Flag[59]`）累计 `Annulus_Num_Count>0` | L334-342 |
| 2→3 | 底行**不再**需补线（`!Right_Add_Flag[59]`） | L353-359 |
| 3→4 | 底行又需补线 **且** `Left_Add_Line[59] > Left_Add_Line[Line_Count+4]`（**边线向左延伸 → 排除进环误判**） | L343-350 |
| 4→0 | 底行不再需补线 **且** `Annulus2_Delay==0` → 清 `Annulus_Flag` | L360-371 |

> 右环镜像 L374-414。**关键防误判**：3→4 的"边线继续向环外延伸"校验（L345/L387）——只有边界确实还在往外扩，才认为"真的进了环、正在绕"。这是纯视觉的**方向性证据**，不需要陀螺。

### 3.5 结论（具体）

1. **"预设环序"其实被作者弱化**：决赛版退出靠视觉状态机（与我方同构），预设只定"左/右"。**不必羡慕"预设环序"**。
2. **他们的时间兜底(`Annulus2_Delay=15`) 是"最短保持"，我方 8s 保险是"跑完就关"**——**语义正交，不冲突**。我方更彻底的"到点强制结束"在测试环境是优点。**保持我方 8s 保险**。
3. **可学 AA（防误判）**：3→4 的"**边界必须继续向环外延伸**"是我方没有的**方向性校验**。我方 `br2_detect_exit`（点1）只有"右缘≥166"等**静态几何**，没有"相对前几帧还在扩"的动态校验。→ 给点1/点2 检测加一条"**边界随时间外扩**"的确认（比较 `now` 与 `-N帧` 的同侧边线位置），可显著降低误退/误进。
4. **可学 AA（大小环）**：`Annulus_Nums∈(10,35)` 用**环口黑点段宽度**区分大小环。我方目前无。**仅当赛道同时存在大/小环时**才需要（当前反方向测试若只有单一大环，先不做）。
