## 三、三个机制缺口再次被判实（与第3轮完全同款）

## 四、为什么这次这么容易盲？（没有图像无法定论）

f455 的盲区从"岔路+洞"标志开始。成功轮过这里也有 1-2 帧闪断——说明这个位置本身就容易全白（大概率是**白色区域/大接头/岔路口**）。差别在于：
- 成功轮：低速到达（~500）→ 白区只占视野一部分 → 1 帧就恢复
- 本轮：**~1300 高速到达** → 进入白区的瞬间曝光/视野全白 → 连续 2.2 秒全白

**这就是你问图像的真正价值所在——如果这一秒有图，我们就能 100% 确认它在那一刻看到了什么。**

## 附：关于"记录模式不记录图像"（回答你的问题）

**对，连续记录模式（P20.7 短按）只记 8 路数字信号**，不存图像：
```
中线 / 舵令 / 标志位 / br2相位 / 速度 / 陀螺 / 左横断 / 右横断
```
原因：一帧灰度图 = 120×188 = 22.5KB，而记录要 500~2000 帧——需要 11~45MB，板上没这么大内存。所以当初设计成"数字通道 + 单帧快照"两个功能：

- **存单帧**（P20.7 长按）：把**当时那一帧灰度图 + 中线快照**存进 RAM（`line_trace` 缓冲），我可以读出来渲染成 PNG。**但一次只能存一帧**，而且必须在现场按——过去跑的记录没法补图。
- 这就是为什么前面两轮分析我只能推理"为什么盲"而不能确认。

**如果你想以后复盘能看到图**，我可以在固件里加一个"自动存帧"功能（比如检测到连续全白 ≥2 帧时自动把那一帧存下来，你跑完我读出来——一次跑能抓到盲区现场的那一帧）。这属于诊断功能、不碰行车逻辑，但按铁律先报你批准再动。
