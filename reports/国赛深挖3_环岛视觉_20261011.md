## 〇、本轮"新增事实"清单（一句话版）

1. **NEUQ 的"直线拟合度评分"是死代码。** `TS_Region_Evaluate` 里的 `L_deviation/R_deviation`（L551-552）恒为 0——因为 `TS_Find_region` 里采集左右边缘点的代码整段被注释（L315-334），`TS_Fit_LR_LineAndDeviation` 调用也被注释（L549）。→ **普查版把"拟合直线度评分"列为可学项，需修正：决赛版实际评分 = "均行宽 7~25px 的连通域里取面积最大者"（L561-570）。**
2. **NEUQ 的"预瞄点"= 连通域最顶部 5 行的像素均值**（BFS 过程中动态维护，L295-309 → L369-372），不是独立的后处理。这是**极廉价的前瞻点**，语义等同我方 `far_mid`（rows 38..52 均值）。
3. **NEUQ 有一条硬失败保险**：任一连通域面积 > `H*W/4` 即**整帧返回失败**（L337-339）。环岛/十字的大白块会直接让该帧"无路"，与我方"顶住上一帧中心"是相反的（他弃、我撑）处置。
4. **HammerTa 环岛是 9 态 + "几何比例特征"判据**（不是像素位置模板）：进环/出环全靠 `CrossRow_L/R`（从中心向外扫、连续黑≤4 的**白占比**，L338-398）、`Cross_col`（中心列白占比，L310-336）、`apex` 角点行列、边线标准差 `S_jugde`。**位置无关**，换场地不用重标——这是我方模板式检测器最值得补的一课。
5. **HammerTa 出口补线是"对侧单边 + 斜率外推过 apex"**（L1183-1196）：`k=(apex.Col-right.Col[0])/(apex.Row-right.Row[0])`，把对侧真边线延长穿过 apex。与 22届/CQU 的"画线穿越"同族，但**用斜率先解出**再外推。
6. **HammerTa 中线的宽度基准是静态手调表 `TrackWild[120]`**（L142-149，2→153），**不是在线学习**。我方 `t->width[y]` 用 `(exp*7+new)/8` 在线学习（`track_core.c:302-305,325-328`）——**我方更抗场地变化，此项保持**。
7. **HammerTa 有全局"单元素锁"**：`element_flag==IN_JUGED` 时三叉/T弯/车库/环岛互相**拒绝启动**（L1003,1037,1336,1402）。我方环岛与十字判定之间无此互斥。

## 一、NEUQ TopSpeed —— 连通域 + 预瞄点（目标 #3）

**文件**：`sources/B_二维视觉算法/Ryan-5853__NEUQ_TopSpeed_CrossCountry_TC377/code/TopSpeed_App/TopSpeed_Vision/TS_Vision_Connected_Domain.c`（681 行，TC377 越野赛，**无环岛**，纯中线视觉）。

### 1.1 主流程 `TS_CD_find_line`（L457-521）

```c
int32_t TS_CD_find_line(uint8_t *frame){
    if(TS_OTSU_with_bias_with_erode(frame,temp,CD_H_USE*CD_W_USE,1.2f)==0){ // L466 大津+偏置1.2+腐蚀

    int num=TS_Find_region(temp,frame,Regs,5,CD_H_USE*CD_W_USE/4);            // L478 最多5域，面积上限 H*W/4

    if(aim_index>=0){ *((int16_t*)&res)=Regs[aim_index].preaim_x;             // L504 返回预瞄点
```

### 1.2 连通域标记 `TS_Find_region`（L232-391）—— BFS 8邻域

- **队列**：静态环形队列 `Point queue[10000]`（L98-121）。
- **起点判据**：从上到下、从左到右扫，`bin[idx]==255 && (x==0||bin[idx_left]==0)`（L247）——白像素且左邻为黑 = 新域起点。
- **特征**：`area`、`sum_x/sum_y→cx/cy`（L362-363）、`max/min_x/y`、`sum_gray→average_gray`（L366）。
- **★ 预瞄点（在 BFS 里顺手算）**：当发现更小的 `min_y`（更靠上的行）时**重置并重新累计**；此后凡 `p.y<=min_y+5` 的像素都累加（L295-309）。收尾 `preaim_x/y = sum/count`（L369-372）；无预瞄点时退化为重心（L373-376）。
  → **含义：预瞄点 = 该连通域"最顶部 5 行"的平均位置**，天然取"看得最远、最干净"的位置。
- **无效判据**（全部满足才保留，L382）：
  ```c
  hit_bound==0 && area>100 && (max_x-min_x) < (max_y-min_y)*1.2
  ```
  - `hit_bound`：队列溢出（域太大撑爆 10000）→ 丢弃；
  - `area>100`：太小的斑不要；
  - **宽 < 1.2×高**：排除"过宽的白块"（噪声/背景大片白）。
- **★ 硬失败**（L337-339）：`if(reg_temp.area > max_area) return 0;` —— `max_area=H*W/4`。**只要有任一块面积超过 1/4 屏，整个 `TS_Find_region` 立即返回 0，全帧失效。**
- **边缘点采集整段注释**（L315-334）：`left_edge_pts/right_edge_pts` 不再生成。

### 1.3 域评分 `TS_Region_Evaluate`（L535-593）—— 真相与普查版不同

**结论（具体）**：
1. **范式不同、我方不落后，且更适合本车**。NEUQ 是"块状"思路（越野线宽、场景干净），我方是"链状"思路（赛道有岔口/环岛/蓝缝，必须逐行分段）。**不建议整体迁移到连通域**。
2. **可学 AA（P2，廉价）**：把 NEUQ 的**"均行宽带"先验**做成一票否决项并入 `vt_seed_ok`——即"本帧候选链的平均行宽必须落在 `[K1·学习路宽, K2·学习路宽]` 带内"，**而不是只看单行的 `VT_SEG_MIN/MAX`**。我方单行过宽只挡那一行（L180），块状大白（如环岛内壁融成一片）仍可能整链通过；加一条**链级均宽**门槛，能在"环内壁+干扰边融合成一条超宽链"时更早拒绝。
3. **可学 AA（P3）**：NEUQ 的"顶 5 行预瞄点"提示：我方 `far_mid` 是**固定行带** 38..52（L567）。若赛道/安装角度变化，固定带可能落在"已铺满的横带"上。可选升级：让 `far_mid` 带**随可信行上限自适应**（取"最上方连续可信行段的下 5 行"），与 NEUQ 一样跟着域顶走。**当前不紧迫**（我方 `degraded`/`measured` 阈值已能兜住）。
4. **反向借鉴**：NEUQ 的"面积>H*W/4 整帧判废"**不能学**——它会让环岛口那几帧直接"没路"，我方在环内需要的是"撑过去"，不是"报无路"。**保持我方 hold 策略。**

### 2.2 几何特征函数（位置无关判据的来源）

```c
float CrossRow_L(int star){          // L338 ★ 左半区白占比
  for(i=0;i<5;i++) row[i]=star+5*i;  // 5 行：star, star+5, ... star+20
  for(i=0;i<5;i++) for(j=94;j>5;j--){          // 从中心(94)向左扫

  }

}
float CrossRow_R(int star){ ... for(j=94;j<183;j++) ... }        // L369 右半区，同构
float Cross_col(){                                            // L310 中心列白占比
  int col[5]={84,90,94,98,102};                                // 5 根中心列
  for(i<5) for(j=119;j>0;j--){ WHITE→++; else 连续黑>4 break; }  // 自下而上

```

- **`CrossRow_L/R(y)`**：第 y 行附近 5 行的"从中心向外、连续黑≤4 的白占比"。**进环时环口一侧会突然变白**（白占比高），另一侧仍被环壁挡（白占比低）。
- **`Cross_col()`（`CorssCol`）**：中心 5 列的白占比，代表"正前方是不是整片白"（路口/环口的标志）。
- **`apex`**：由 `Left_Apex()/Right_Apex()` 得到的角点（`Apex_Row/Apex_Col/Row[]/Col[]/Mark`）——**环岛进出全靠 apex 的行列变化**。
- **`S_jugde()`（L405+）**：边线到拟合直线的标准差，`L_S/R_S` 越小越"直"。用于"环口一侧应出现弯折"的判别。

### 2.3 ★ 出口补线：对侧单边 + 斜率外推过 apex（L1179-1196）

**我方比对**：我方 `big_ring` 在 LOOP/TAIL **只夹中点**（`mid<80 → 118`，`big_ring.c:175-181`），**从不合成边界**——这与深挖2对 CQU 的判断一致。HammerTa 给出了"**用真实对侧边线（right.Col）+ 过 apex 的斜率外推**"造出内侧线，再 `mid = 该线 ∓ TrackWild/2`。

### 2.6 结论（具体：我方 XX 在 YY 场景会 ZZ，可学 AA）

1. **【P1】我方模板式检测器"位置锁定"，HammerTa 的几何比例判据"位置无关"。**
   我方 `br2_detect_arm/mouth/exit`（`big_ring.c:52-98`）全部是**固定像素带 + 硬阈值**（如 `y41-56 且 rs[0]>=140`），标定自 3 帧、容忍 ±20~30px。→ **换场地/换入环横向偏移时，一旦环口不在标定列，检测器整帧静默**（v133 实车"全程未触发"正是此机理的预演）。
   **可学 AA**：给三个检测器**各加一路位置无关特征**并"或"进计数（命中任一即算命中）：
   - 用 `CrossRow` 式"中心向外扫、连续黑≤4 的白占比"算 **left/right opening ratio**，取"一侧 >0.9 且对侧 <0.4"作进环特征；
   - 用"逐行白段右端/左端的极值行"算 **apex**（而非固定 y 带），以 apex 的**相对位移**（如 apex.Row 进入某区间、apex.Col 越中线）作进出环特征。
   这样保留现有模板（已验证），同时补上"横向位置变化"的鲁棒性。**风险低、收益直击 v133 的失效模式。**

2. **【P1】我方 DONE 之后缺少"出环过渡"。**
   我方 `big_ring` 一旦 `BR2_DONE` 就**直接返回、零注入**（`big_ring.c:117`），把方向盘立刻交回 `track_core` 普通巡线。而 HammerTa 在退出后**仍有 `OUT_ROUND` 态**（L1295-1317，用 `RacingLine_R(2)` 单边补线走向内），直到 `cross_row_L<0.7` 才回 `NO_ROUND`。
   → **我方在"出环瞬间视觉尚未恢复"时，普通巡线可能把车带向环外**（TAIL→DONE 后第一帧无保护）。
   **可学 AA**：DONE 后加一个 **~600ms 的"出环过渡期"**，期间维持最后一段的内侧单边补线（或冻结最后 mid）+ 降速；过渡期结束再清 `special_route`。与 v141 的 TAIL 保护同族，**只是把保护延伸到 DONE 之后**。

3. **【P2】±10px 邻域续边法可作环内兜底。**
   我方逐行链在边界点断开后走"模型插值"（`track_core.c:546-551` 上下可信行线性插值）。HammerTa 的 `L1976-1992/L2250-2278` 是"**在上一行边点 ±10px 内找跳变**"，**比纯斜率插值更贴真实边**。
   **可学 AA**：给 `vt_take_row` 失败的行加一条"邻域找回"支路——在上一可信行边界 ±10 内重新搜边，命中则当测量、否则才插值。**环内/急弯收益最大**（那时边界最容易被遮挡 1~2 行）。

4. **【P2】"单元素锁"值得补。**
   我方 `track_core.element()`（L630-664）里，环岛 phase≠NORMAL 时**仍可能被 `corner_left&&corner_right` 抢判为 `VT_CROSS`**（L637 在 NORMAL 分支内，但 NORMAL→CROSS 的切换不受环岛态保护；环岛态走 else 分支，故实际不冲突——**但 `special_route` 帧会强制 `phase=NORMAL`**，L691，这等于在特殊路径上**主动放弃**环岛状态机）。→ **若将来环岛与十字路段重叠（比赛布局可能存在），会出现状态互踢。**
   **可学 AA**：引入一个"当前处理中的 element"锁（环岛进行中 → 抑制 fork/hole 触发的十字判定与 `special_route` 清 phase），避免互踢。**防御性，P2。**

5. **【保持/不学】**：`TrackWild[120]` 静态宽度表**不学**（我方在线学习更抗场地）；`middleline=0/188` 的整段钉死**不学**（过于依赖标定，我方 hold 更稳）。
