# 技术架构

> 目标：一台 188×120 灰度摄像头、双电机差速、单舵机的循迹车，
> 在 40 秒内跑完含大圆环的赛道。

---

## 一、系统总览

```
┌──────────────────────── CPU1 ────────────────────────┐
│  MT9V03X 摄像头 (188×120 灰度, 全局快门)              │
│      │ DMA 双缓冲                                     │
│      ▼                                                │
│  DMA 完成中断 → 快照到 cam_gray（防撕裂）             │
└───────────────────────┬──────────────────────────────┘
                        │ 共享内存 / 只读
┌───────────────────────▼──────────────────────────────┐
│                       CPU0                            │
│                                                       │
│  ① 二值化      两级递归 Otsu（黑 / 蓝 / 白）          │
│       │                                               │
│  ② 边线提取    左右边界分离 + 双边界连续性            │
│       │        贴边行单边补线（学习路宽）             │
│  ③ 中线生成    可信测量行 + 模型插值（同帧对齐）      │
│       │                                               │
│  ④ 事件识别    路口 / 岔路 / 洞 / 终点 / 环岛三锚点   │
│       │                                               │
│  ⑤ 控制        PID 转向 + 速度环(PWM/12) + 陀螺阻尼   │
│       │        盲区降速 / 丢线爬行 / 堵转保护         │
│  ⑥ 执行        舵机 P33.9 (50Hz) + 双电机 P02.4-7     │
│                                                       │
│  ⑦ 记录        2000 样本环形缓冲（8 路信号）          │
│  ⑧ 诊断        DAS hot-attach 只读回读                │
└───────────────────────────────────────────────────────┘
```

**为什么 CPU0/CPU1 分离**：摄像头 DMA 和图像处理在 CPU1，控制与决策在 CPU0，互不阻塞。CPU0 只读快照，不碰 DMA。

## 二、视觉流水线

### 2.1 二值化：两级递归 Otsu

```
一级 Otsu：暗类（黑胶带） | 亮类（蓝底 + 白路）
    │
    ├─ 亮类占比 ≤ 62%  → 说明画面里蓝白不多，一级够用
    │
    └─ 亮类占比 > 62%  → 对亮类再跑一次 Otsu
                          ↓
                    蓝底 | 白路
```

**参数**：`OTS_L1_GUARD_PCT = 62`、`OTS_L1_MIN_SEP = 10`、`OTS_L2_MIN_RANGE = 12`

**为什么必须两级**：赛道是"蓝底 + 白路 + 黑胶带"三色。一级 Otsu 只能分出"黑/非黑"，蓝和白会被合并——车会把蓝区当白路开进去。

### 2.2 边线提取：双边界连续性

```
从最下方 14 行取种子（必须过 vt_seed_ok：宽度/位置/形态）
    │
    ▼
向上逐行 + 向下逐行：左端和右端必须同时落在上一行窗口内（±12px）
    │
    ├─ 单边贴边（白段被画面裁掉）→ 用可见边 ± 学习路宽/2 补出另一边
    │
    └─ 两边都找不到 → 该行标记为"不可信"
```

**关键参数**：

| 参数 | 值 | 含义 |
|---|---|---|
| `VT_SEG_MIN` | 12px | 白段最小可信宽度 |
| `VT_SEG_MAX` | 150px | 超过视为"整片铺满" |
| `VT_EDGE_WIN` | 12px | 相邻行边界最大位移 |
| `VT_SEG_K` | 4 | 每行最多记 4 个白段（岔口行） |
| `VT_SEED_ROWS` | 14 | 种子只从最下方 14 行找 |
| `VT_WID_LO/HI` | 40% / 250% | 白段宽度合理区间（相对学习宽度） |

### 2.3 中线生成：测量 + 模型

```c
// 只信任"左右边界都在画面内"的行
measured = 可信测量行数
model_rows = 用最近可信行插值/外推补出的行数

// 近处和远处来自同一条模型 → 天然对齐
```

**为什么这样做**：贴边行的中点必然偏向被裁侧，直接用它会导致中线"底部在左、顶部在右"的断崖（v104 的核心修复）。

### 2.4 事件识别

| 事件 | 判据 | 动作 |
|---|---|---|
| 路口（`crossing`） | `FULL 行 ≥ 24` 且 `measured < 8` | 顶住上一帧中线，降级限速 320 |
| 岔路（`fork`） | 多段白 + 宽度突变 | 不甩大方向 |
| 洞（`hole`） | 行内暗区宽度异常 | 保持直行 |
| 终点（`finish`） | 斑马线特征 | `fault=10` 自动停车 |
| 全白（`all_white`） | 整帧无边界 | 100 帧 ≈2s 后 `VT_LOST` 停车 |

## 三、控制

### 3.1 转向

```
误差 e = (mid - 中心) × 系数        // mid: 0..188, 中心 94
陀螺阻尼 e -= clamp(gyro / 30000, ±0.06)
转向 = Kp·e + Ki·∫e + Kd·de
舵机 = 740 + 转向 × 行程
```

- 中位 **740 raw = 1480us**（750 会左偏）
- 行程：右 85 raw / 左 65 raw（实测极限各留 10us）

### 3.2 速度

```
目标速度 = 基础档 460
          弯道限速：cap = 460 - (bend-4)×8，最多砍 200
          转向限速：cap = min(cap, 400 - |steering|)
          盲区：连续 ≥2 拍无有效线 → 每拍 -160，压到 450
          丢线：爬行 150
          ↓
      速度环（编码器反馈）：PWM = f(目标, 实际)  // 输出上限 3060
          ↓
      差速：内轮 = pwm × (100 - duty/2) / 100
```

**单位换算**（读记录时用）：
- `center = mid × 128 / 188`
- `steer = 度 × 10`
- `speed = PWM / 12`（上限 3060）

### 3.3 三个安全网

| 安全网 | 触发 | 动作 |
|---|---|---|
| 盲区降速 | ≥2 拍无有效线 | 压爬行 + 跳 PI |
| 丢线爬行 | ≥25 帧无有效线 | 朝上次方向满舵 + 爬行 |
| 全白停车 | 100 帧全白（≈2s） | `VT_LOST` 停车 |
| 堵转保护 | 编码器无变化 + PWM 高 | 压 PWM / 停车 |

## 四、大圆环状态机（big_ring）

### 4.1 六相位

```
OFF ──点3确认(2hit/165ms)──▶ ARMED(P1) ──点2确认──▶ TURN(P2, 右转 mid=124)
                                                          │ 600ms
                                                          ▼
DONE(P6) ◀──点1确认── TAIL(P5) ◀──直行600~1500ms── STRAIGHT(P4) ◀──再遇点2── LOOP(P3, 巡线)
                                                          ▲                            │
                                                          └────── 环内 ≥1200ms ────────┘
```

### 4.2 三锚点检测器（行段几何）

| 锚点 | 判据（行号 y 自上=远） |
|---|---|
| 点3（武装） | y41-56 单段且右缘 ≥140 且左缘 12..95，行数 ≥8；且 y18-31 右缘 85..160，行数 ≥8；且 y100-119 左缘最小 ≥8 |
| 点2（口） | y26-48 存在"多段 + 末段右缘 ≥162 + 首段左缘 ≥25"的行 ≥2，且末段左缘逐行收敛 ≥2 次；且 y100-119 左缘最小 ≤26 |
| 点1（退出） | y18-28 末段右缘 ≥166，行数 ≥4；且 y30-42 末段右缘 112..160，行数 ≥4 |

**稳健性**：以三帧为种子，合成 30 个平移/亮度变体 + 8 个负样本做参数搜索，容忍 ±20~30px / ±8行。

### 4.3 关键参数

| 参数 | 值 | 作用 |
|---|---|---|
| `BR2_CONFIRM_WIN` | 165ms | 确认窗口（≈5 帧） |
| `BR2_TURN_BIAS` | 30 | 进环右转注入：mid = 94+30 = 124 |
| `BR2_TURN_MS` | 600ms | 右转持续 |
| `BR2_LOOP_MIN_MS` | 1200ms | 进环后最短再检出（防刚进环二次触发） |
| `BR2_STRAIGHT_MS` | 600~1500ms | 出环口直行保持 |
| `BR2_LEFT_SOFT_MID` | 80 | 环内左转协调阈值（<80 改右转 118） |
| `BR2_GUARD_MS` | 8000ms | 车发动起 8s 未 DONE → 强制关闭 |
| `BR2_PREMOUTH_WIN` | 1200ms | v148 顺序竞态补救窗口 |

### 4.4 隔离原则

- **BIG OFF** → 环岛逻辑完全不执行
- **DONE** → 注入 / 左转协调全部失效
- 环岛改动**只允许**动 `big_ring.c/h`，环外零改动并核验

## 五、记录与诊断

### 5.1 记录通道（P20.7）

| 操作 | 功能 |
|---|---|
| 短按 | 连续记录 开 / 停 |
| 长按 | 存单帧（灰度 + 中线快照） |

- 容量 2000 样本，采样实测 **110~131ms/样本**（不是标称 59ms）→ ≈2 圈
- 8 路信号：`center / steer / flags / br2(相位) / speed / gyro / clip_left / clip_right`

### 5.2 自动存帧

连续 **3 拍**无有效线 → 自动把该帧灰度存入 `line_trace` 缓冲（`cam_saved_auto=1`），
附带 meta：`flags / br2 / ms / recf`。

**9 张盲区存帧，全部是过曝型**——这是"盲区不是阈值问题"的关键证据。

### 5.3 DAS 只读回读

- CPU0 DSRAM：`0x70000000 - 0x70012000`（用 `das_read_memory.exe`，4 字节对齐）
- CPU1 DSRAM（摄像头）：`0x60000000` 起（用 `das_read_camera_memory.exe`，≤1024B/块）
- **读之前必须确认 ELF 与板上固件匹配**（符号地址会漂移）

## 六、内存布局与约束

| 区域 | 用途 | 注意 |
|---|---|---|
| CPU0 DSRAM 0x70000000+ | 记录数组、帧结构、控制状态 | **连续分配，余量 ~18KB**；加变量先算余量 |
| CPU1 DSRAM 0x60000000+ | 摄像头帧缓冲 | 块读 ≤1024B |
| PFlash | 代码 | 只烧 PFlash，校验逐行 checksum |

**踩坑**：加 28 字节变量也曾触发 `ltc E112`。腾挪手法：诊断数组缩容（-5.7KB）。
