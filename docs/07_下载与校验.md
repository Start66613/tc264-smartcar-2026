## 二、怎么合并分卷

### Windows (cmd)

```cmd
copy /b 03_versions_all.zip.01 + 03_versions_all.zip.02 + 03_versions_all.zip.03 + 03_versions_all.zip.04 + 03_versions_all.zip.05 + 03_versions_all.zip.06 03_versions_all.zip
```

### Git Bash / Linux / macOS

```bash
cat 03_versions_all.zip.0* > 03_versions_all.zip
```

### 校验

```bash
# Windows
certutil -hashfile 03_versions_all.zip SHA256
# Linux / macOS
sha256sum 03_versions_all.zip
```

## 三、03 包里面是什么

```
_versions/     ← 早期版本（Senior6 / CamLine / RCManual / 里程碑）
outputs/       ← 后期版本（VisionTrack v108~v148 等）
```

每个 zip 都是**完整工程**（`user/` + `code/` + `libraries/` + `Debug/`），
可以直接用 AURIX Development Studio 打开、编译、烧录。

> 只想看某个版本的源码？用仓库里的 `versions/<工程>/<版本名>/`，
> 那是抽取出来的纯源码（不含 3MB 的逐飞库），可以直接 diff。

## 四、完整性说明
