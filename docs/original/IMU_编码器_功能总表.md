## 三、国赛代码里"直接能抄"的三条（优先级最高）

1. **陀螺系数 0.00685**（Jason）→ 重新接入阻尼，一改就有效果

3. **环口判定用"白段消失→再出现"的沿变**（Jason 环岛状态机；本项目 v059 已采用）

## 四、⚠️ 不能抄的部分（重要）
Jason（双车跟随）是 **2D 摄像头车**（`ImageDeal[0..59]` 60 行、`Pixle[60][80]`），
**逐行"补线/跳变点"那套在 1D 的 128 像素 CCD 上无法实现**。
能移植的是：**状态机、判定逻辑、控制律、保护机制**。

## 六、速度决策（Jason `speed_decision`，比我们精细）

```c
if (point_W >= 0.85 && 两侧直线度 <= 0.35)      // 长直道
        Speed = max;                             // → 全速
else    Speed = max - (int)expf(k1 * (1 - point_W));   // → 指数减速（不是线性！）
```
- `point_W` ≈ "前方赛道可信度/笔直度"（0~1）；**越弯越不确定 → 指数级降速**
- 分道路类型预设速度：`Speed_Cire_In/Out=180`（环内/环）、`Speed_podao=210`（坡道）、`Speed_obstacle=180`（避障）
- **我们的现状**：`target -= mag*600`（线性）。**可升级为指数**：`target -= expf(K*(1-可信度))`

## 七、差速实现细节（`speed_dif1/speed_dif2` 两版）
```
speed_dif1（二次曲线版，推荐）:
    x = 转向量 * 系数;  限幅 turn_edge=350;
    y = -0.014344 + 0.0078637x - 0.000014484x*x;
    外轮目标 = 基准*(1 + turn_k*y);          turn_k = 0.3875
    内轮目标 = 基准*(1 - turn_k*y*1.25);     ← 内轮多刹 25%

speed_dif2（线性+前瞻级别版）:
    turn_level = 前瞻点/10 + 1;
    外轮 = 基准*(1 + turn_k*turn_level*x*0.01);
    内轮 = 基准*(1 - turn_k*turn_level*x*0.01);   ← 对称
```
- 左右转向用**不同的系数** `Left_Speed_Co / Right_Speed_Co`（配合转向机左右不对称）
- `LimitLeft/LimitRight(duty)` 转向也分左右限幅 —— **与我们 v042 的 L170/R130 做法一致** ✓
