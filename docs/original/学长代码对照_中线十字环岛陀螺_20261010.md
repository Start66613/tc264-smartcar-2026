## 二、中线怎么计算

**NEUQ（TC377，总钻风）**：
1. Otsu(带偏置)+腐蚀二值化；
2. **BFS 连通域**（8邻域，最多5个域），每域提取：面积/重心/包围盒/**每行最左最右点**/平均灰度/**顶部5行平均位置=预瞄点**；
3. 域筛选：碰边淘汰、面积<100 淘汰、**宽 > 1.2×高 淘汰（排除"过宽白块"）**；
4. 域评分（TS_Region_Evaluate）：**左右边线最小二乘拟合 x=k·y+b**，用拟合偏差当"弯曲度"——弯曲度和>2 判定为锥桶剔除；偏好"宽、不碰边、连续延伸、亮"的引导线；
5. 输出**预瞄点**（选中域顶部 5 行的平均位置）→ 转向误差 = 预瞄点x − 图像中心。
> 关键思想：**不逐行输出中线**，而是"从所有连通物里选最像赛道的一团，取它的远端预瞄点"。
> 与我们 v121 的"种子海选/长链优先"同一个思想；它多走了一步：宽度上限排除+拟合直线度评分+预瞄点瞄准。

**CQU（TC264）**：逐行左右边线 + Findpoint 特征（leftup/leftdown/rightup/rightdown/lcenter/rcenter/trueshort/duan/斑马线），误差 err[0]=近处行误差，err[] 全行成组。

**我们（现状）**：逐行双边界追踪+模型插值+全帧加权中值；v121 起底部链与中部长廊按真实链长竞争选种。

## 三、十字路口

- **SJTU cross.c**（精读过）：双 L 角点 → CROSS_BEGIN（按近线走，aim_distance=0.4 前瞄）→ CROSS_IN：**切换"远线"**——在两侧固定列(far_x1/far_x2)向下找远端边线并跟踪；哪侧远线存在就跟哪侧；两侧各重新取得>20点才退出。= "保持原方向 + 找远处同方向的路"。
- **CQU**：靠 connect_line 拉线补线 + 正常巡线通过；有斑马线提示位。
- **我们（v119/v120 已做）**：不可信中线不许指挥转向（直行兜底）；J1 静态帧已修。

## 四、环岛怎么处理（CQU 左环；右环镜像）

**检测与阶段推进（视觉特征 + 陀螺角度双门限）**：
- 0→1：多特征同时满足（leftdown + lcenter + 右侧短段 + 非左短段 + 左端 + 非右端 + 非斑马线 + 里程>100）→ 确认环口；
- 1→2：特征恢复时——**清零陀螺积分、记录 ang_in**；
- 2→3→4：上方角点 leftup 出现 → leftup.y>45；
- **4→5：陀螺累计转过 10°**；**5→6：转过 45° 且看到对面 rightdown**；**6→7：转过 64° → 判定该出环**；
- 7→8→9：leftup 出现/消失二次确认 → 回正常。
**环内每阶段用 `connect_line` 强制画线**（例：stage1 从(55,30)拉到(5,115)）——**不是看环壁走，而是按阶段规则画路**，误差按画出的线提取。

**环内舵机**：切 "ServControl1 + ServControl"（非模糊）；其核心 ——
`Error = (视觉误差 − 陀螺角速度)/10` → P/I/D → OutPut → `pout = pout0 − P·OutPut`。
**陀螺角速度直接进转向算式**（微分/阻尼效应）；平时模糊控制也带 `(Error−Yawrate)` 阻尼项。

（SJTU circle.c：BEGIN/IN/RUNNING/OUT/END 五阶段纯视觉、远线切换、无陀螺。HammerTa 环岛纯视觉。NEFU 陀螺用于坡道。）

## 五、"陀螺仪判断绕环 + 辅助打舵"可行性（三种用法，可叠加）

1. **进度门限（CQU 式）**：进环清零 → 10°/45°/64° 卡阶段，解决"暂时看不到环壁时不知道转到哪"。→ 我们 `big_ring.c` 已有雏形（口型确认+净转角 315° 出环），当前被暂停；升级成"四环通用+分环参数"即可用。
2. **角速度阻尼（日常+环内）**：转向算式加 `−kw·YawRate` 项，治摆头/稳出弯。前提：**先标定陀螺比例与符号**（我们之前正是因为未标定才从转向里拿掉——现在可以补标定）。
3. **角速度目标环（进阶）**：环内/大弯令目标偏航角速度 ω*≈v/R，陀螺闭环打舵——"自己量着圈转"。用编码器速度+标定系数即可。

**可移植性**：CQU 与我们**同芯片、同相机、同 IMU、同逐飞库**——结构直接抄，常量换我们的标定；NEUQ 是 TC377 但纯 C，抄思路不抄常量。

## 六、建议实施顺序（待用户拍板）

1. **陀螺标定 + 转向角速度阻尼项**（半小时级，先小系数）→ 治摆头、稳高速。
2. **升级 big_ring.c 为四环通用状态机**（CQU 式：视觉确认→陀螺角度门限→分段拉线），先单环测。
3. （可选，后做）中线借鉴 NEUQ：宽度上限排除过宽白块 + 拟合直线/预瞄点远瞄准。
