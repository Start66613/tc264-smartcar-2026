# 大圆环状态机设计文档（反向行驶 · TC264 视觉智能车）

> **平台**：TC264（Infineon AURIX）智能车 · 视觉循迹
> **模块**：`big_ring.c` / `big_ring.h`（代号 br2）
> **版本**：v135 · 2026-10-11 · 两轮实车完整验证通过
> **说明**：本文公开设计思路与全部代码，供参考交流。文中的行号/阈值为**本车特定相机安装与赛道**的标定值，直接照搬大概率不可用，请按第 7 节重新标定。

> **一句话概括**：在「进环前 / 环口 / 出环后」三个位置各标定一个视觉锚点特征，用一个小状态机串联「武装 → 右转进环 → 环内巡线 → 直行出环 → 退出」，所有动作通过改写视觉中线注入执行；全程带逐帧诊断记录与超时兜底。

---

## 1. 问题背景

赛道含一个"大圆环"（环形岛），要求车从环口进入、绕行一圈、找到出口后恢复直行。
本车有两个特殊点：

1. **反向行驶**：相对赛道原设计方向，本车是反着跑的。环口的视觉结构与正向完全镜像，原有的"正向"环岛逻辑（基于左贴边 + 分离走廊）对反向入口**完全无法识别**（离线喂帧验证：0 命中）。
2. **环内大面积白区**：环内二值化图像以白为主，传统"找左右边界求中线"的几何方法在环内极不稳定，容易锁错线。

因此方案的基本约束是：

- 只在环岛相关区域接管动作，其余路段**零影响**；
- 任何一步失败都必须能**兜底退出**，不能把车卡死在特殊状态；
- 判据必须**可离线标定、可回归测试**，不靠"看一眼感觉对"。

## 2. 总体思路：三锚点 + 状态机

核心思想：**不去"理解"环的几何结构，而是在行进路线上标定三个瞬间可识别的视觉锚点**，用一个小状态机把"什么时机做什么动作"串起来：

| 锚点 | 位置 | 特征作用 | 触发动作 |
|---|---|---|---|
| **点3** | 进环前直道 | 进环前预告 | 静默"武装"（不动作） |
| **点2** | 环口（分流处） | 第 1 次出现 = 进环口；第 2 次出现 = 出环口 | 第1次：右转进环；第2次：直行出环 |
| **点1** | 出环后直道 | 环岛动作完成 | 退出（全静默） |

每个锚点用一个**独立的检测器**（单帧二值图的行段几何，见第 4 节）。检测器之间互不依赖；状态机只关心"当前状态下该看那个检测器"，其余检测器即使误触发也不会造成动作（状态机上下文天然过滤）。

**备选方案（曾记录、未采用）**：右转进环后立即退出模块、完全交回普通巡线，行驶到"再遇点2"时再处理直行——不依赖点1识别。本实现选择"停留到点1确认再退出"（更可控；若点1难以识别可切换备选）。

## 3. 状态机设计

### 3.1 状态与转移

```
       点3           点2(第1次)         [环内]         点2(第2次)         点1
        │               │                │               │               │
        ▼               ▼                ▼               ▼               ▼
  ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
  │   OFF    │──▶│  ARMED   │──▶│   TURN   │──▶│   LOOP   │──▶│ STRAIGHT │──▶│   TAIL   │──▶ DONE
  └──────────┘   └──────────┘   └──────────┘   └──────────┘   └──────────┘   └──────────┘
      静默           静默          右转进环       环内巡线+禁左    直行出环        等点1        全静默
                  (30s超时→DONE)                (25s超时→DONE)                (8s超时→DONE)
```

| 状态 | 含义 | 转出条件 | 注入动作 |
|---|---|---|---|
| `OFF` | 待机 | 点3 确认 → `ARMED` | 无 |
| `ARMED` | 已武装（保持静默） | 点2 确认 → `TURN`；超时 30s → `DONE` | 无 |
| `TURN` | 右转进环 | 固定 600ms → `LOOP` | 右转（mid=124） |
| `LOOP` | 环内巡线 | 环内 ≥1.2s 且点2 再次确认 → `STRAIGHT`；超时 25s → `DONE` | 左转禁令 |
| `STRAIGHT` | 直行出环 | ≥600ms 且点2 消失（上限 1.5s）→ `TAIL` | 直行（mid=94） |
| `TAIL` | 等待出环标志 | 点1 确认 → `DONE`；超时 8s → `DONE` | 左转禁令 |
| `DONE` | 完成，全静默 | （本轮不再参与；仅重新起跑 / 关开关重置） | 无 |

### 3.2 命中确认：165ms 窗口

单个检测器输出是"帧级布尔量"，高速下容易单帧抖动或漏检。所有锚点确认统一采用：

> **165ms 窗口内累计 ≥2 次命中** → 判定"该特征出现"。

### 3.3 动作注入：直接改写视觉帧

模块**不直接控制舵机**，而是直接改写视觉帧（VTFrame）的字段，让主控制律"以为"中线在那里，从而自然输出想要的转向：

- `mid = 94 + 30 = 124`：把中线放到画面右侧 → 主控制律给出右转 → **右转进环**；
- `mid = 94`：中线归中 → **直行**；
- `LOOP` / `TAIL` 中 **`mid < 94` 一律夹到 94**：**左转禁令**——环内只许直行和右修，禁止左打（防止环内锁错线掉头，见第 5.3 节）。

同时设置 `valid=1, degraded=1, all_white=0`、`measured/confidence` 给安全值、`special_route=1`：保证该帧不会被"低可信中线守卫"驳回、不误报全白/丢线，并在降速档下执行。

### 3.4 超时兜底

每个等待状态都有超时，任何超时都直接进入 `DONE`（全静默、交回普通巡线）：

```c
#define BR2_ARMED_TO_MS   30000u  /* 武装后等进环口 */
#define BR2_LOOP_TO_MS    25000u  /* 环内等"再遇点2" */
#define BR2_TAIL_TO_MS     8000u  /* 等点1（≈"跑完就关"兜底） */
```

`DONE` 是**终点态**：进入后每次调用直接返回、不做任何注入，并且**本次起跑内不会重新武装**——因此即使忘记手动关闭模块，它也不会在后续路段做任何事。

## 4. 视觉特征检测器（行段几何）

### 4.1 定义

- 二值图 188×120（1=白色道路）。行号 `y`：0=最远，119=最近（底部）。
- **白段**：一行内连续白像素 ≥16px 的一段（过滤噪点与细黑胶带残缺）；每行最多取 4 段。
- 记号：`n`=该行段数；`ls[i]` / `rs[i]` = 第 i 段的左缘 / 右缘 x 坐标。

### 4.2 三个检测器

**点3 · 武装（arm）** —— 三条同时满足：

```
y41..56  : 单段(n==1) 且 右缘≥140 且 左缘∈[12,95]      → ≥8 行
y18..31  : 末段右缘∈[85,160]                           → ≥8 行
y100..119: 左缘最小值 ≥8
```

**点2 · 环口（mouth）**：

```
y26..48  : 多段(n≥2) 且 末段右缘≥162 且 首段左缘≥25 的行  → ≥2 行
           其中"末段左缘逐行收敛（比上一行小 >2px）"       → ≥2 次
y100..119: 左缘最小值 ≤26
```

**点1 · 退出（exit）**：

```
y18..28  : 末段右缘≥166     → ≥4 行
y30..42  : 末段右缘∈[112,160] → ≥4 行
```

### 4.3 为什么用"行段几何"

- 判据都是**单帧可判定**的局部结构（某几行的段数 / 段缘范围 / 收敛趋势），不需要多帧跟踪，也不依赖中线稳定性；
- 特征"出现在哪几行、取值什么范围"可以从真实帧离线数出来 → 可标定、可写测试；
- 误触发由状态机上下文抑制（arm→OFF；mouth→ARMED/LOOP；exit→TAIL），跨状态单帧误报无害。

## 5. 稳健化：从"±5px 失效"到"±30px 可用"

### 5.1 教训：单帧标定必死

v133 首版直接用停车拍摄的 3 帧逐像素标定。实车一跑：**检测器偏移 ±5px 即失效**，全程从未触发（首跑失败，相位一直停在 OFF）。原因：实车行驶时的相机姿态、光流、二值化边界与停车帧的差异远大于 5px。

### 5.2 方法：变体合成 + 负样本 + 参数搜索

1. **合成变体**：以三帧为种子，合成 30 个变体——横向平移（±5/10/20/30px）、纵向平移（±4/8 行）、亮度偏移（±15 灰阶）；
2. **收集负样本**：8 张真实负样本（其他路段、路口、失败帧），要求全部**不能**触发；
3. **参数搜索**：在 PC 上批量跑"变体全命中 + 负样本全静默"，得到 **横向容忍 ±20~30px、纵向 ±8 行**（比首版提升约 4~6 倍）；
4. **回归固化**：把 33 项正样本 + 8 个负样本写成 C 测试（`test_bigring_rev_detect.c`），每次改参数必须全过。

### 5.3 左转禁令（v135：针对实车事故的修复）

**事故**（修复前的实车记录）：环口回程时视觉锁到画面左侧的线（mid 由 100 快速掉到 69→34），追踪器打出满左舵 +10° 持续约 1.3s，车在环内**掉头往回跑**（陀螺积分由 -66684 反向到 +39128）。

**修复**：进环后至退出前（`LOOP`/`STRAIGHT`/`TAIL`），**任何左转中线（mid<94）一律夹到 94**（直行）。

- 数据依据：环内干净巡线段仅 1~2 帧轻微左偏（夹掉无影响）；事故段每一帧都被夹回 → 不可能再打出左转掉头；
- 实车复核：修复后两轮完整记录中，禁令窗口内**零左偏样本**；
- 参数 `BR2_LEFT_BAN_MID=94` 可按需降低到 86~90（允许轻微左修）。

## 7. 移植指南（换车 / 换赛道如何重新标定）

检测阈值与本车相机安装强相关，**移植必须重新标定**。步骤：

1. **采锚点帧**：把车停在三个锚点位置，各存一帧原始灰度帧（按你固件的同款二值化流程处理成二值图）；
2. **逐行 dump**：用工具（`diag_bigring_features.c`）打印每行白段结构，找出"只在该位置出现"的几何特征；
3. **写判据**：按第 4.2 节的格式给出"行范围 + 段数/段缘条件 + 计数阈值"；
4. **变体回归**：合成平移 / 亮度变体 + 收集负样本，参数搜索至"变体全过、负样本全静默"；
5. **固化测试**：写成回归测试，上车先跑测试再实车验证。

常用调参速查：

| 现象 | 调整 |
|---|---|
| 右转不足 / 过头 | `BR2_TURN_BIAS`（偏置）、`BR2_TURN_MS`（时长） |
| 环内过早报"再遇点2" | `BR2_LOOP_MIN_MS` 调大 |
| 出环直行太长 / 太短 | `BR2_STRAIGHT_MS` / `BR2_STRAIGHT_MAX` |
| 退不出来（等点1超时） | 检查点1检测；`BR2_TAIL_TO_MS` 兜底 |
| 环内想要轻微左修 | `BR2_LEFT_BAN_MID` 降到 86~90 |

## 8. 已知限制

- 检测器参数依赖相机安装与二值化效果，换车需重新标定；
- 目前只处理"一个"大圆环（单次触发；`DONE` 后本轮不再参与）；
- 环岛以外的路段问题与本模块无关（数据验证：模块 `DONE` 后全静默、零注入）。

 uint32_t dbg;   /* v134 诊断：bit0 arm命中 bit1 mouth命中 bit2 exit命中（原始检测器输出，每帧刷新） */
} BR2State;

#include <stdlib.h>

/* 可调参数（首次实车后按现象微调） */
#define BR2_TURN_BIAS     30     /* 右转注入偏置：mid=94+bias（e<0 → 右转） */
#define BR2_TURN_MS       600u   /* 右转持续时间 */
#define BR2_LOOP_MIN_MS   1200u  /* 进环后最短再检出时间（防刚进环立即二次触发） */
#define BR2_STRAIGHT_MS   600u   /* 出环口直行保持（最短） */
#define BR2_STRAIGHT_MAX  1500u  /* 直行保持上限 */
#define BR2_ARMED_TO_MS   30000u /* 武装后等待进环口超时 → 放弃 */
#define BR2_LOOP_TO_MS    25000u /* 环内超时（没等到二次口）→ 放弃 */
#define BR2_TAIL_TO_MS     8000u /* 等待点1超时 → 结束（8秒兜底，相当于方案B的"跑完就关"） */
#define BR2_CONFIRM_WIN   165u   /* 特征确认窗口：165ms(≈5帧@33ms)内累计>=2次命中即触发 */
/* v135 左转禁令：环内（进环后至退出完成前）mid 下限。mid<此值=向左打舵，一律夹回。
   94 = 画面中心 = 直行；实车若发现车贴外沿/弯走不圆，可酌情降到 86~90（一行调参）。 */
#define BR2_LEFT_BAN_MID  94

static int segments(const uint8_t *b,int y,int *ls,int *rs)
{
 int x=0,n=0;
 while(x<VT_W){int l,r;if(!b[y*VT_W+x]){x++;continue;}
  l=x;while(x<VT_W&&b[y*VT_W+x])x++;r=x-1;
  if(r-l+1>=16&&n<4){ls[n]=l;rs[n++]=r;}
 }
 return n;
}
int br2_detect_arm(const uint8_t *bin)
{
 int y,c1=0,c2=0,minL=9999;
 for(y=41;y<=56;y++){
  int ls[4],rs[4],n=segments(bin,y,ls,rs);
  if(n==1&&rs[0]>=140&&ls[0]>=12&&ls[0]<=95)c1++;
 }
 for(y=18;y<=31;y++){
  int ls[4],rs[4],n=segments(bin,y,ls,rs);
  if(n>=1&&rs[n-1]>=85&&rs[n-1]<=160)c2++;
 }
 for(y=100;y<=119;y++){
  int ls[4],rs[4],n=segments(bin,y,ls,rs);
  if(n>=1&&ls[0]<minL)minL=ls[0];
 }
 return c1>=8&&c2>=8&&minL>=8;
}
int br2_detect_mouth(const uint8_t *bin)
{
 int y,c1=0,conv=0,prevl=-1,minL=9999;
 for(y=26;y<=48;y++){
  int ls[4],rs[4],n=segments(bin,y,ls,rs);
  if(n>=2&&rs[n-1]>=162&&ls[0]>=25){
   c1++;
   if(prevl>=0&&ls[n-1]<prevl-2)conv++;
   prevl=ls[n-1];
  }else prevl=-1;
 }
 for(y=100;y<=119;y++){
  int ls[4],rs[4],n=segments(bin,y,ls,rs);
  if(n>=1&&ls[0]<minL)minL=ls[0];
 }
 return c1>=2&&conv>=2&&minL<=26;
}
int br2_detect_exit(const uint8_t *bin)
{
 int y,c1=0,c2=0;
 for(y=18;y<=28;y++){
  int ls[4],rs[4],n=segments(bin,y,ls,rs);
  if(n>=1&&rs[n-1]>=166)c1++;
 }
 for(y=30;y<=42;y++){
  int ls[4],rs[4],n=segments(bin,y,ls,rs);
  if(n>=1&&rs[n-1]>=112&&rs[n-1]<=160)c2++;
 }
 return c1>=4&&c2>=4;
}
void br2_reset(BR2State *s){memset(s,0,sizeof(*s));s->phase=BR2_OFF;}
/* v134 窗口确认：165ms 内累计 >=2 次命中即触发（容忍高速下的单帧漏检/闪烁）。 */
static int confirm(BR2State *s,int seen,uint32_t stamp)
{
 if(!seen)return 0;
 if(stamp-s->last_hit>BR2_CONFIRM_WIN)s->hits=0;
 s->last_hit=stamp;
 if(++s->hits>=2u){s->hits=0;return 1;}
 return 0;
}
static void enter(BR2State *s,uint32_t phase,uint32_t stamp)
{s->phase=phase;s->stamp=stamp;s->hits=0;s->last_hit=0;}
void br2_process(BR2State *s,VTTracker *t,const uint8_t *bin,VTFrame *f,
 uint32_t enabled,uint32_t running,uint32_t imu_valid,int32_t yaw10)
{
 int am,mo,ex;
 (void)t;(void)imu_valid;(void)yaw10;
 if(!enabled){br2_reset(s);return;}
 if(!running||s->phase==BR2_DONE)return;
 if(f->sequence!=s->seq){
  s->seq=f->sequence;
  /* v134 诊断：每帧刷新三个检测器原始输出（供记录通道回读） */
  am=br2_detect_arm(bin);mo=br2_detect_mouth(bin);ex=br2_detect_exit(bin);
  s->dbg=(uint32_t)((am?1:0)|(mo?2:0)|(ex?4:0));
  switch(s->phase){
   case BR2_OFF:
    if(confirm(s,am,f->stamp))enter(s,BR2_ARMED,f->stamp);
    break;
   case BR2_ARMED:
    if(confirm(s,mo,f->stamp)){
     s->count_mark2=1u;s->entered_ms=f->stamp;
     s->hold_until=f->stamp+BR2_TURN_MS;
     enter(s,BR2_TURN,f->stamp);
    }else if(f->stamp-s->stamp>BR2_ARMED_TO_MS)enter(s,BR2_DONE,f->stamp);
    break;
   case BR2_TURN:
    if(f->stamp>=s->hold_until)enter(s,BR2_LOOP,f->stamp);
    break;
   case BR2_LOOP:
    if(f->stamp-s->stamp>=BR2_LOOP_MIN_MS&&confirm(s,mo,f->stamp)){
     s->hold_until=f->stamp+BR2_STRAIGHT_MAX;
     enter(s,BR2_STRAIGHT,f->stamp);
    }else if(f->stamp-s->stamp>BR2_LOOP_TO_MS)enter(s,BR2_DONE,f->stamp);
    break;
   case BR2_STRAIGHT:
    if(f->stamp-s->stamp>=BR2_STRAIGHT_MS&&(!mo||f->stamp>=s->hold_until))
     enter(s,BR2_TAIL,f->stamp);
    break;
   case BR2_TAIL:
    if(confirm(s,ex,f->stamp))enter(s,BR2_DONE,f->stamp);
    else if(f->stamp-s->stamp>BR2_TAIL_TO_MS)enter(s,BR2_DONE,f->stamp);
    break;
   default:break;
  }
 }
 /* 注入（每次调用都执行，与是否新帧无关） */
 if(s->phase==BR2_TURN){
  f->mid=94+BR2_TURN_BIAS;f->far_mid=f->mid;
  f->valid=1;f->degraded=1;f->all_white=0;f->measured=20;f->confidence=45;
  f->special_route=1;f->special_fault=0;
 }else if(s->phase==BR2_STRAIGHT){
  f->mid=94;f->far_mid=94;
  f->valid=1;f->degraded=1;f->all_white=0;f->measured=20;f->confidence=45;
  f->special_route=1;f->special_fault=0;
 }else if(s->phase==BR2_LOOP){
  /* v135 左转禁令：环内左转中线一律夹回直行（实车事故：回程锁左侧线→满左舵掉头） */
  if(f->mid>=0&&f->mid<BR2_LEFT_BAN_MID)f->mid=BR2_LEFT_BAN_MID;
  if(f->far_mid>=0&&f->far_mid<BR2_LEFT_BAN_MID)f->far_mid=BR2_LEFT_BAN_MID;
  f->special_route=1;f->special_fault=0;
 }else if(s->phase==BR2_TAIL){
  /* v135 左转禁令（续）：出环口后、点1确认前同样禁止左转 */
  if(f->mid>=0&&f->mid<BR2_LEFT_BAN_MID)f->mid=BR2_LEFT_BAN_MID;
  if(f->far_mid>=0&&f->far_mid<BR2_LEFT_BAN_MID)f->far_mid=BR2_LEFT_BAN_MID;
 }
}
