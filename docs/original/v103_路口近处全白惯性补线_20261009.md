## 一、现场反馈

用户把车**静止放在十字路口**，反馈"**他看不到中线**"，随后明确要求"**你可以读数据啊，现在车就在十字路口**"
—— 要求直接用板载摄像头数据诊断，而不是靠推理。

板上当时跑的是 v102（`3D5A19AF`，`fault=3` = `VT_LOST` 停在路口）。

## 二、数据驱动的根因（真实帧，非合成图）

用 `scripts/read_camera_frame.py cam_gray` 从 **CPU1 DSRAM** 分块 dump 出 188×120 灰度帧，
`scripts/analyze_frame.py` 离线复刻固件大津法后逐行看白段结构：

```
cam_gmin=0  cam_gmax=255  contrast=255          ← 不是低对比度问题
Otsu threshold = 199

y=110 .. y=48 : 段数=1 宽=187  → 整行全白(wide)     ← 近处 63 行，路面横向铺满
y=45 .. y=28  : 段数=1 宽=57~75 中心=92~93          ← 远处 19 行，单段真实道路

分析区间 y=110..28（83 行）:
  整行全白 : 63 行       单段正常 : 19 行
  近处 y>=90 单段正常行数 = 0
```

结论：路口处**近处全白、远处才有一点真实边界**。于是：

| 失效环节 | 数值 |
|---|---|
| `valid` 三项条件 | `valid=19 < 20` ❌ ｜ `near=0 < 6` ❌ ｜ `wsum=0` ❌ |
| `v->valid` | **0** → 判"看不到道路" |
| `vt_step` | 走丢线分支 → 连续 10 帧后 **`VT_LOST` 停车**（`fault=3`） |

## 三、v102 为什么没治好（关键坑，值得记）

v102 已经加了"整行全白 → 沿用上次中心"的补线，但闸门用的是 **`valid>0`**：

```c
if(previous>0 && valid>0 && wide_fill<VT_WIDE_FILL_MAX && wide){ ...补线... }
```

**这是个死锁**：扫描是 `for(y=110; y>=28; y--)` 自下而上（近→远），而 `valid` 只在
"选中真实边界段"时才 `++`。路口处 **y=110 一上来就是 wide 行**，全部被 `continue` 跳过，
`valid` 要等扫到 **y=28~47 的远处行**才会变成 1 —— 也就是说，**近处需要补线的那些行，
在判断时 `valid` 还是 0，补线永远不启动** → `near=0` → `valid` 条件再次失败 → 停车。

> `valid>0` 想挡的是"跑出赛道整帧全白也直冲"，但用错了位置：它是**循环结束后**才知道的量。

## 四、v103 改动（`track_core.c` / `track_core.h`）

1. **删掉循环内的 `valid>0` 闸门**，补线条件改为：
   `previous>0 && wide_fill<VT_WIDE_FILL_MAX && (wide || max_w > road_w*3/2)`
   —— 新增 `max_w`（本行最宽白段）跟踪，把判据从"仅整行全白"放宽为"**整行全白 或 白段显著宽于学到路宽**"。
2. **防误判闸门移到循环之后**，改用 `real_rows`（真实边界行计数）：
   ```c
   v->valid = valid>=20 && near>=6 && wsum>0;
   if(real_rows==0) v->valid=0;   /* 一行真实边界都没有、全靠惯性补出来的 → 不算看到道路 */
   ```
   `real_rows` 与 `valid` 的区别：**补线行不计入 `real_rows`**，所以它才能如实回答
   "这帧到底有没有真的看到路"。
3. **整帧全白兜底分支**（路口 / 冲出赛道两种图长得一样，只能靠时间区分）：
   ```c
   else if(real_rows==0 && max_w>=VT_W/2 && t->previous_mid>0){
     v->mid=t->previous_mid; v->far_mid=t->previous_mid;
     v->degraded=1; v->all_white=1;        /* 不设 valid */
   }
   ```
   新增结构字段 `VTFrame.all_white`、`VTControl.white_frames`、宏 `VT_WHITE_MAX_FRAMES 100`（≈2s）。
4. **补线占比过高即降级限速**：`if(wide_fill>=VT_WIDE_FILL_MAX/2) v->degraded=1;`
5. **`vt_step` 整帧全白超时**：
   ```c
   if(v->all_white){ if(++c->white_frames>=VT_WHITE_MAX_FRAMES){vt_control_stop(c,VT_LOST);return;} }
   else c->white_frames=0;
   ```
   `vt_control_stop` 中清零 `white_frames`。

参考：国赛学长 `CalculateCenterLine` 的「**全白 → 沿用上次值**」。
