## 三、关键指标定义（读记录时对照）

| 记录列 | 含义 | 换算 |
|---|---|---|
| `center` | 中线位置（0..128） | `mid = center × 188 / 128` |
| `steer` | 舵令 | 实际角度 = `steer / 10`（度） |
| `speed` | 速度 | PWM = `speed × 12`（上限 3060） |
| `flags` | 位标志 | bit0=有效, bit1=降级, bit2=全白, bit3=岔路, bit4=洞, bit5=终点 |
| `br2` | 环岛相位 | 0=OFF, 1=ARMED, 2=TURN, 3=LOOP, 4=STRAIGHT, 5=TAIL, 6=DONE |
| `gyro` | 陀螺 Z 轴 | 原始值，正=左转 |
| `cl/cr` | 左右边界 | 像素列 |

**fault 码**：`1`=手动停、`3`=丢线停（VT_LOST）、`5`=堵转、`10`=终点（VT_FINISH）

## 四、怎么复读这些数据

### 4.1 读板上记录（实车跑完立刻做）

```bash
cd D:/智能车
# ① 先确认板上固件与 ELF 匹配（关键！）
python scripts/read_vision_track_report.py      # 看 hex_sha256
# ② 读 2000 帧记录
python scripts/read_track_trace.py > tmp/trace.txt
```

### 4.2 读存帧

```bash
# 绝对不能接 | head（SIGPIPE 会留下旧文件）
python scripts/read_camera_frame.py line_trace > tmp/read.log 2>&1
# 核验：连续两次读，sha256 必须不同
```

### 4.3 回放/分析

```bash
# 帧直方图
python - <<'PY'
data = open('tmp/frame_saved.bin','rb').read()
hist=[0]*256
for v in data: hist[v]+=1
t=len(data)
print(f"过曝 {sum(hist[240:])*100/t:.1f}% | 中间调 {sum(hist[100:180])*100/t:.1f}% | 暗 {sum(hist[:100])*100/t:.1f}%")
PY

# 逐行 dump（需要 edge_mode）
gcc ... scripts/diag_cross_frames.c ... && ./diag_cross_frames.exe --edge3
```

### 4.4 数据文件在哪

| 类型 | 位置 |
|---|---|
