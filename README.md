## 这是什么

一台基于 **逐飞 TC264D** 的摄像头循迹智能车，从 2026-10-05 写下第一行代码，到 2026-10-11 上场比赛。

这个仓库不是"成功学复盘"，而是一份**带证据链的工程档案**：

- 每个版本都能回退（源码 + HEX 指纹 + 逐字节复现验证）
- 每个改动都有数据支撑（15 轮实车记录、9 张盲区存帧、862 帧成功轮）
- 每个失败都留着（被否决的方案、回退记录、误判与修正）

## 三句话总结

1. **赢在"先数据后改动"**：每一次调参都对着记录里的帧号和数值，不靠手感。v143 的盲区降速就是 6 次失败记录逼出来的唯一正解。
2. **输在"盲区"**：环岛所有失败都伴随 ≥1 秒的长盲区；这不是阈值问题——存帧证明那段画面里真的没有线。
3. **真正带走的是流程**：影子验证 → 四门禁 → 烧录 → 回读 → 归档。它让 198 个版本里没有一个"说不清是什么"的固件。

## 诚实声明

- 比赛当轮**没有板上记录**（未开记录通道），40s 为用户计时报告。
- 环岛识别只做了**右环**；四环中的左环/其余环未实现（`element()` 里已有通用 FSM，未接）。
- 遗留缺陷 3 项（锁舵机僵持、B-1 丢线计数、相机偶发无信号），详见 `docs/01` 第五节。
